# Skill 模板说明

Skill 是注入智能体 Prompt 的 Markdown 指令。框架只要求技能目录中存在合法 `SKILL.md`；模板用于展示最小文档合同，不规定章节、目录、文件数量或工程规模。

## 自由工作区

技能可以只有一个简短 `SKILL.md`，也可以在同一目录放入任意层级参考资料、脚本、图片、模板、数据或完整配套工程。`references/`、`scripts/`、`assets/` 等名称只是常见习惯，不是必需目录，也不要为了匹配样例创建空结构。

额外文件不会自动注入 Prompt、注册成 Provider 工具或自行执行。应在 `SKILL.md` 中用相对路径说明何时读取和如何使用；真正执行脚本仍需要智能体拥有相应工具权限。完整工程可以保留原结构，Skill 只负责描述使用路径和安全边界。

## 作用域

| 作用域 | 路径 | 使用者 |
|--------|------|--------|
| `agent_create` | `users/<user>/user_skills/agent_create/<name>/` | 主智能体与 `self_improve` |
| `user_create` | `users/<user>/user_skills/user_create/<name>/` | 当前用户主智能体 |
| `shared` | `shared_skills/<name>/` | 获准使用该共享技能的用户 |

## SKILL.md 合同

- 第一个非空行必须是唯一一级标题。
- 一级标题后的首段用于技能描述；后续正文可以按任务需要自由组织。
- 可选 `## Tool` 只用于文档化参数，不能注册真实可执行工具。
- 不得保存密钥、Token、Cookie、密码或私人数据。

`skill_creater` 只创建或更新 `SKILL.md`。创建后可以继续用正常文件工具完善整个目录；更新会保留额外文件，删除会删除完整技能目录及其所有配套资源。
