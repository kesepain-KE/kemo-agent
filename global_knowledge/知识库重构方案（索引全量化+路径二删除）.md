# 知识库重构方案：索引全量化 + 按需检索路径删除

## 一、问题

当前知识库系统存在两个问题：

### 问题 1：知识索引被硬编码字符限制截断

```python
# run/prompt.py → 第 48 行
KNOWLEDGE_INDEX_MAX_CHARS = 8000
```

`select_knowledge_index()` 只读取每层的索引文件（`data_structure.md` / `index.md` / `索引.md` / `目录.md`），这些文件本身就是轻量的目录描述，平均几百字符。用 8000 字符限制反而增加了维护者的认知负担——"到底有没有截断？被截了哪些内容？"

而且这个限值是**硬编码常量**，没有在 `global_config.json` 的 `prompt.char_limits` 中出现，用户无法通过配置调整。

### 问题 2：存在两条冗余的知识检索路径

| 路径 | 函数 | 用途 | 现状 |
|------|------|------|------|
| 路径一（Index） | `select_knowledge_index()` | 注入索引总览到 system prompt | ✅ 必要，保留 |
| 路径二（Search） | `select_knowledge()` + `build_index()` + `knowledge_search` 插件 | 按用户提问做全量文本关键词检索 | ❌ 冗余，交给 kemo-graph 项目 |

路径二（RAG 按需搜索）涉及一整套基础设施：
- `run/knowledge.py` 中 6 个函数 + 1 个 dataclass + 4 个常量
- `plugins/knowledge_search/` 整个插件（SKILL.md + tool.py）
- `tests/test_prompt_knowledge.py` 中 5 个测试用例
- `agents/task_plan/` 子代理的工具白名单和文档引用
- `agents/_runtime/resources.py` / `schema.py` 中的权限校验逻辑
- `run/tools.py` 中的 kemo_graph 替代逻辑

这套路径已被决策移除，交给独立的 `kemo-graph` 项目处理。

---

## 二、方案

### 知识索引全量化

去掉 `KNOWLEDGE_INDEX_MAX_CHARS` 硬编码限制，`select_knowledge_index()` 不再做截断，始终注入完整的索引文件内容。索引文件本身是轻量的目录描述，不会造成 prompt 膨胀。

### 路径二整条删除

按依赖关系从叶子到根清理：

```
plugins/knowledge_search/    ← 最外层插件，先删
  └─ tool.py (调 build_index)

run/knowledge.py              ← 核心，删路径二函数
  ├─ _terms()                 ← 只被 select_knowledge 调用
  ├─ _read_text()             ← 只被 _iter_documents 调用
  ├─ _iter_documents()        ← 只被 build_index 调用
  ├─ build_index()            ← 被 select_knowledge + knowledge_search 调用
  ├─ select_knowledge()       ← 无调用者后删除
  └─ KnowledgeSelection       ← 无调用者后删除

agents/task_plan/              ← 子代理引用清理
agents/_runtime/               ← 权限校验简化
run/tools.py                   ← 工具过滤清理
tests/test_prompt_knowledge.py ← 测试用例清理
```

### `run/knowledge.py` 重构后的面貌

```python
"""轻量级文件知识索引注入。"""

from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path

from run.prompt_sources import iter_files, read_required_text


_INDEX_NAMES = frozenset({"index.md", "data_structure.md", "索引.md", "目录.md"})


@dataclass(frozen=True, slots=True)
class KnowledgeDocument:
    scope: str
    path: Path
    relative_path: str
    title: str
    content: str


@dataclass(frozen=True, slots=True)
class KnowledgeIndexSelection:
    documents: tuple[KnowledgeDocument, ...]
    text: str
    original_chars: int
    injected_chars: int
    original_items: int
    injected_items: int
    truncated: bool


class KnowledgeError(RuntimeError):
    pass


def _title(path: Path, content: str) -> str:
    for line in content.splitlines():
        stripped = line.strip()
        if stripped.startswith("#"):
            heading = stripped.lstrip("#").strip()
            if heading:
                return heading
    return path.stem


def select_knowledge_index(
    root: Path,
    user: str,
    *,
    scopes: tuple[str, ...] = ("user", "shared", "global"),
) -> KnowledgeIndexSelection:
    """全量注入所有层的索引文件，无字符截断。"""
    available_scopes = (
        ("user", root / "users" / user / "knowledge"),
        ("shared", root / "shared_knowledge"),
        ("global", root / "global_knowledge"),
    )
    documents: list[KnowledgeDocument] = []
    pieces: list[str] = []
    allowed_scopes = set(scopes)
    for scope, base in available_scopes:
        if scope not in allowed_scopes:
            continue
        for path in iter_files(base, names=_INDEX_NAMES):
            content = read_required_text(path)
            if not content:
                continue
            document = KnowledgeDocument(
                scope=scope,
                path=path,
                relative_path=path.relative_to(base).as_posix(),
                title=_title(path, content),
                content=content,
            )
            pieces.append(f"[{scope}:{document.relative_path}]\n{content}")
            documents.append(document)
    full_text = "\n\n".join(pieces)
    total = len(full_text)
    return KnowledgeIndexSelection(
        tuple(documents), full_text,
        total, total,
        len(documents), len(documents), False,
    )
```
