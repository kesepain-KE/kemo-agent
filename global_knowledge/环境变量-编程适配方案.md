## 一、完整环境变量 + 逐项解释

```env
# kemo-agent 环境变量
```

### Provider 密钥 — 兜底层

```env
KEMO_API_KEY=YOUR_KEMO_API_KEY
```
- **类型**：字符串
- **含义**：Kemo 网关的 API Key
- **优先级**：`user_config.json` 中 `provider.api_key` > 此环境变量 > 报错
- **源码影响**：Provider 初始化时，先读 `user_config.json` 的 `api_key` 字段，为空才读 `KEMO_API_KEY` 环境变量

```env
KEMO_BASE_URL=http://127.0.0.1:8741/v1
```
- **类型**：字符串
- **含义**：Kemo 网关地址
- **默认值**：留空时默认 `http://127.0.0.1:8741/v1`
- **源码影响**：Provider 的 `base_url` 来源：`user_config.json` > `KEMO_BASE_URL` > 硬编码默认值

```env
KEMO_MODEL=
```
- **类型**：字符串
- **含义**：兜底模型名
- **生效条件**：仅当 `user_config.json` 中 `provider.model` 为空时使用
- **源码影响**：Provider 模型名读取链：`user_config.json.model` > `KEMO_MODEL` > Provider 默认

---

### OpenAI 兼容模式

```env
OPENAI_API_KEY=your-openai-api-key
```
- **类型**：字符串
- **含义**：OpenAI 或兼容 API 的 Key
- **生效条件**：仅当 `provider.type = "openai"` 时使用
- **源码影响**：同 `KEMO_API_KEY` 的优先级链，但走 OpenAI 分支

```env
OPENAI_MODEL=
```
- **类型**：字符串
- **含义**：OpenAI 兜底模型名

```env
OPENAI_BASE_URL=https://api.openai.com/v1
```
- **类型**：字符串
- **含义**：OpenAI API 端点
- **用途**：可改为 Azure、代理商中转等兼容地址

### 网络代理

```env
HTTP_PROXY=
HTTPS_PROXY=
```
- **类型**：字符串
- **含义**：HTTP/HTTPS 代理地址
- **留空时**：直连
- **源码影响**：Provider 发起 HTTP 请求时，读取此环境变量设置代理

---

### 工具插件

```env
TAVILY_API_KEY=
```
- **类型**：字符串
- **含义**：Tavily 搜索引擎的 API Key
- **留空时**：`tavily_search` 插件不可用
- **源码影响**：插件初始化时检测此变量，为空则禁用 Tavily 相关工具

### Web 服务

```env
WEB_HOST=127.0.0.1
```
- **类型**：字符串
- **含义**：Web 监听地址
- **`127.0.0.1`**：仅本机可访问
- **`0.0.0.0`**：暴露到局域网
- **源码影响**：创建 HTTP 服务时传入的 `host` 参数

```env
WEB_PORT=1357
```
- **类型**：整数
- **含义**：Web 监听端口
- **冲突行为**：端口被占用时自动轮询下一个端口（最多尝试 10 次）
- **源码影响**：创建 HTTP 服务时传入的 `port` 参数

```env
WEB_ACCESS_TOKEN=
```
- **类型**：字符串
- **含义**：Web 访问令牌
- **认证方式**：非空时，用户在 URL 后带 `?token=xxxx` 访问，不再使用 `Authorization: Bearer` 请求头
- **留空时**：不启用 token 鉴权
- **源码影响**：
  - 从 URL 查询参数 `?token=` 读取令牌
  - 与配置值比对进行鉴权
  - 移除旧的 `Authorization` 请求头解析逻辑

```env
WEB_USERNAME=
```
- **类型**：字符串
- **含义**：该智能体使用者的用户名
- **与内部多用户的关系**：这是**登录 Web 页面的人**的用户名，并非智能体内部的多用户系统。简单说就是「谁在用这个 AI」
- **留空时**：不启用账号密码登录
- **源码影响**：登录表单验证时，用户名匹配此变量

```env
WEB_PASSWORD=
```
- **类型**：字符串
- **含义**：该智能体使用者的用户密码
- **与内部多用户的关系**：同 `WEB_USERNAME`，这是登录密码，与智能体内部多用户无关
- **留空时**：不启用账号密码登录
- **源码影响**：登录表单验证时，密码匹配此变量

```env
WEB_SESSION_SECRET=
```
- **类型**：字符串
- **含义**：Session 签名密钥，用于加密 Session Cookie
- **留空时**：**自动生成**一个随机密钥，浏览器记录登录状态
- **默认有效期**：2 小时
- **源码影响**：
  - 检测此变量，为空则调用随机生成函数创建密钥
  - Session 过期时间设置为 2 小时

```env
WEB_SESSION_COOKIE_NAME=kemo_agent_session
```
- **类型**：字符串
- **含义**：Session Cookie 的名称
- **多实例场景**：同一台机器部署多个 kemo-agent 实例时，各实例用不同的 Cookie 名称避免 Session 冲突
- **源码影响**：设置 Cookie 时的 `name` 参数

## 二、变更清单

### 已删除

| 变量 | 原因 | 源码清理点 |
|------|------|-----------|
| `HTTP_VERIFY_SSL` | 网络插件不再依赖此全局配置 | 移除 `network` 插件中读取此变量的逻辑 |
| `WEB_ALLOW_CONFIG_WRITE` | 不再支持 Web 写入 `user_config.json` | 移除 Web 端配置写入接口及相关鉴权逻辑 |

### 已调整

| 变量 | 旧行为 | 新行为 | 源码改动点 |
|------|--------|--------|-----------|
| `WEB_ACCESS_TOKEN` | 从 `Authorization: Bearer` 请求头读取 | 从 URL 查询参数 `?token=xxxx` 读取 | 修改鉴权中间件，将 token 来源从 header 改为 query param |
| `WEB_SESSION_SECRET` | 启用认证时必须手动填写 | 留空时自动生成随机密钥，Session 默认有效期 2 小时 | 新增自动生成逻辑，设置 Session 过期时间为 7200 秒 |
| `WEB_USERNAME` 注释 | "留空则不启用登录鉴权" | "该智能体使用者的用户名，与智能体内部的多用户设计无关" | 无代码改动，仅注释更新 |
| `WEB_PASSWORD` 注释 | 无解释 | "该智能体使用者的用户密码，与智能体内部的多用户设计无关" | 无代码改动，仅注释更新 |

## 三、核心逻辑变更（需重点实现）

### 1. API Key 完整优先级链

```
┌──────────────────────────────────────────┐
│  1. user_config.json provider.api_key     │  ← 最高优先级
│     （明文密钥，非空即用）                  │
├──────────────────────────────────────────┤
│  2. .env 环境变量                          │  ← 中间优先级
│     KEMO_API_KEY / OPENAI_API_KEY         │
│     （按 provider.type 决定读哪个）         │
├──────────────────────────────────────────┤
│  3. 无可用 Key → 报错                      │
└──────────────────────────────────────────┘
```

**源码位置**：Provider 初始化模块，读取密钥时的 fallback 链

---

### 2. WEB_ACCESS_TOKEN 鉴权方式变更

**旧逻辑**：
```python
# 从请求头读取
token = request.headers.get("Authorization", "").removeprefix("Bearer ")
```

**新逻辑**：
```python
# 从 URL 查询参数读取
token = request.args.get("token", "")
```

**源码位置**：Web 鉴权中间件 / 装饰器

---

### 3. WEB_SESSION_SECRET 自动生成

**逻辑**：

```python
import secrets

SESSION_SECRET = os.getenv("WEB_SESSION_SECRET")
if not SESSION_SECRET:
    SESSION_SECRET = secrets.token_hex(32)  # 自动生成 64 字符随机密钥
```

**Session 有效期配置**：

```python
app.config["PERMANENT_SESSION_LIFETIME"] = timedelta(hours=2)
```

**源码位置**：Web 应用初始化模块

---

### 4. 配置优先级总览（给编程智能体的参考）

项目中所有配置项的最终取值逻辑应遵循以下优先级：

```
用户级 user_config.json（最高）
    ↓ 未配置
环境变量 .env
    ↓ 未配置或不适用
全局级 global_config.json
    ↓ 未配置
源码硬编码默认值（最低）
```
