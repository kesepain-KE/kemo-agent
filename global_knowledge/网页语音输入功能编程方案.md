# kemo-agent 网页语音输入功能 —— 编程方案

## 问题

网页端聊天输入目前仅支持键盘打字，缺少语音输入能力。

## 方案

使用浏览器内置 `SpeechRecognition` API（纯前端，零依赖，不消耗 Token）。

```
用户点击🎤按钮 → 浏览器语音识别（zh-CN）→ 实时转为文字 → 填入聊天输入框
```

**为什么不用后端方案**：
- kemo-agent 是 localhost 访问，SpeechRecognition 的 HTTPS/localhost 限制自动满足
- Chrome/Edge 中文识别效果已经足够好
- 不消耗 API Token，零延迟

**平台限制**：仅 Chromium 系浏览器支持（Chrome、Edge、Opera），Firefox/Safari 不支持。按钮在非 Chromium 浏览器中应隐藏或置灰。

## 详细规划

### 步骤 1：创建语音识别 Hook

**新建文件**：`E:\code\kemo-agent\web\frontend\src\hooks\useSpeechRecognition.ts`

```ts
import { useCallback, useRef, useState } from "react";

interface SpeechRecognitionHook {
  /** 是否正在录音 */
  listening: boolean;
  /** 浏览器是否支持语音识别 */
  supported: boolean;
  /** 开始录音 */
  start: () => void;
  /** 手动停止录音 */
  stop: () => void;
}

export function useSpeechRecognition(
  onResult: (text: string) => void,
): SpeechRecognitionHook {
  const [listening, setListening] = useState(false);
  const recognitionRef = useRef<SpeechRecognition | null>(null);
  const supported = !!(
    typeof window !== "undefined" &&
    (window.SpeechRecognition || (window as any).webkitSpeechRecognition)
  );

  const start = useCallback(() => {
    if (!supported) return;
    const SpeechRecognitionAPI =
      window.SpeechRecognition || (window as any).webkitSpeechRecognition;
    const recognition = new SpeechRecognitionAPI();
    recognition.lang = "zh-CN";
    recognition.interimResults = false;
    recognition.continuous = false;

    recognition.onresult = (event: SpeechRecognitionEvent) => {
      const text = event.results[0][0].transcript;
      onResult(text);
    };

    recognition.onerror = (event: SpeechRecognitionErrorEvent) => {
      console.warn("语音识别错误:", event.error);
      setListening(false);
    };

    recognition.onend = () => {
      setListening(false);
    };

    recognitionRef.current = recognition;
    recognition.start();
    setListening(true);
  }, [supported, onResult]);

  const stop = useCallback(() => {
    recognitionRef.current?.stop();
    setListening(false);
  }, []);

  return { listening, supported, start, stop };
}
```

### 步骤 2：在聊天输入区域添加语音按钮

**文件**：聊天输入组件（具体文件路径由前端代码结构确定，可能在 `ChatPage` 相关的输入组件中）

**操作**：

1. 引入 `useSpeechRecognition` Hook
2. 在输入框旁边（如发送按钮左侧、输入框内部右侧）添加麦克风按钮
3. 点击时调用 `start()`，识别结果通过 `onResult` 回调填入输入框
4. 按钮状态：
   - 不支持 → 隐藏
   - 空闲 → 显示麦克风图标（灰色）
   - 录音中 → 显示红色脉冲动画麦克风

```tsx
import { Mic, MicOff } from "lucide-react";
import { useSpeechRecognition } from "@/hooks/useSpeechRecognition";

// 在聊天输入组件内：
const { listening, supported, start, stop } = useSpeechRecognition((text) => {
  setInputValue(text); // 将识别文字填入输入框
});

// 按钮（放在输入框旁边）
{supported && (
  <button
    type="button"
    onClick={listening ? stop : start}
    className={listening ? "mic-button active" : "mic-button"}
    title="语音输入（中文）"
  >
    <Mic size={20} />
  </button>
)}
```

## 应达到的效果

1. **Chromium 浏览器**（Chrome/Edge）：输入框旁边出现麦克风按钮，点击开始录音，再次点击停止，识别结果自动填入输入框
2. **Firefox/Safari**：麦克风按钮不显示，不影响正常输入体验
3. **录音状态**：录音中按钮变红并脉冲动画，结束后恢复灰色
4. **错误处理**：识别出错时静默恢复，不影响页面（浏览器 API 本身已有错误提示）
5. **零后端改动**：纯前端实现，不涉及任何后端 API
