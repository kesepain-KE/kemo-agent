# 智能体检索规则

## 默认流程

开发问题 → 项目索引 → 目标领域 → 目标模块 → 必要组件 → 直接关系 → 代码证据。

## 默认限制

- 默认只展开一层直接关系。
- 默认最多加载 5～10 篇笔记。
- related_to 不自动展开。
- 无证据的 may_affect 不自动进入主要上下文。
- 不因同目录而加载全部笔记。
- 总览页及其全部子页不得一起自动进入上下文。

## 继续扩展条件

只有当以下内容可能变化时继续展开：
- 接口
- 参数
- 返回值
- 数据结构
- 配置格式
- 共享状态
- 事件协议
- 用户明确要求影响分析

## 适用对象

- 编码任务定位
- 模块修改前的上下文收敛
- 调用链核验
- 配置依赖确认
