# 关系类型规范

## 允许的关系类型

### 结构
- contains
- belongs_to

### 源码
- calls
- called_by
- imports
- depends_on
- implements
- reads
- writes
- registers

### 开发
- tested_by
- configured_by
- documented_by
- may_affect

### 弱关系
- related_to

## 使用原则

- calls / imports / configured_by / tested_by 优先保留源码证据。
- may_affect 仅用于推断，必须明确说明不确定性。
- related_to 只做语义补充，不作为默认扩展依据。
- 不把普通正文提及直接升级成强关系。

## 证据要求

关系尽量记录：
- 源码路径
- 符号名
- 触发条件
- 不发生条件
- 提取或核验方式
- 置信度
- 最近核验日期
