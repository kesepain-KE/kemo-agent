# skills 模板说明

## 什么是技能（Skill）

技能是注入到智能体 system prompt 中的 Markdown 指令文档，用于扩展开箱即用的知识和行为。技能**不注册为 Provider 可执行工具**——它只影响智能体如何思考和回应。

## 技能 vs 插件

| | 技能（Skill） | 插件（Plugin） |
|---|---|---|
| 位置 | `shared_skills/` 或 `users/<user>/user_skills/` | `plugins/` |
| 注入方式 | system prompt 正文 | system prompt 正文 + 注册为 function call |
| 能否被模型调用 | 否（只影响推理） | 是（模型可以 function call） |
| `## Tool` 章节 | 仅文档化展示，不注册工具 | 注册为真实可执行工具 |
| 典型用途 | 代码风格指南、领域知识、操作手册 | 文件操作、网络请求、shell 执行 |

## 技能作用域

| 作用域 | 路径 | 谁可以用 |
|--------|------|----------|
| `agent_create` | `users/<user>/user_skills/agent_create/<name>/` | 主智能体 + `self_improve` 子代理 |
| `user_create` | `users/<user>/user_skills/user_create/<name>/` | 仅主智能体 |
| `shared` | `shared_skills/<name>/` | 所有用户的主智能体 |

## 文件结构

```
<scope>/<skill_name>/
└── SKILL.md    # 唯一必需文件，技能的全部内容
```

可选附加资源（放在同目录下）：

| 目录/文件 | 用途 |
|-----------|------|
| `references/` | 参考文档，SKILL.md 中通过相对路径引用 |
| `scripts/` | 辅助脚本 |
| `assets/` | 图片、模板等静态资源 |

## 模板占位符说明

| 占位符 | 替换为 |
|--------|--------|
| `{{SKILL_TITLE}}` | 技能名称（一级标题） |
| `{{SKILL_DESCRIPTION}}` | 一句话描述 |
| `{{skill_name}}` | 技能英文标识，用于目录名和 Tool schema |
| `{{适用场景描述}}` | 什么时候用这个技能 |
| `{{不适用场景描述}}` | 什么时候不该用 |

## 两种技能类型

### 指令型（instruction）

纯 Markdown 指令，无 `## Tool` 章节。适用于代码规范、知识手册、操作流程等。

示例：`kb_retriever`（知识库检索指南）、`skill_creator`（技能创建流程）。

### 文档化工具型（tool_schema）

包含 `## Tool` 章节和 JSON schema，但仅用于**文档展示**，不注册为可执行工具。适用于需要结构化参数但不想开发插件的场景。

`## Tool` 中的 `input_schema` 只是告诉智能体"这个技能期望什么参数"，实际调用仍需智能体自行判断和执行。
