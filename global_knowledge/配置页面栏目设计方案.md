# kemo-agent Web 配置页面栏目设计方案

> 设计时间：2026-07-21
> 基于截图 `屏幕截图 2026-07-21 161708.png` 及当前 `user_config.json`、`global_config.json` 字段

## 整体布局

保持现有布局不变：左侧纵向 tab 导航 + 右侧卡片式表单。删除「Prompt 与 Expand」和「配置文件 JSON」两个栏目。

最终 6 个栏目：

---

## 1. 外观与主题

> 💾 **存储位置：localStorage**，不写入配置文件

| 控件 | 类型 | 说明 |
|------|------|------|
| 界面主题 | 双卡片切换 | 亮色（高级白）/ 暗色（高级黑） |
| 界面字号 | 三按钮组 | 小(72%) / 中(88%) / 大(105%) |

---

## 2. 模型与 Provider

> 📄 来源：`user_config.json` → `provider` + `multimodal_models`

### 核心连接

| 控件 | 对应字段 | 类型 |
|------|---------|------|
| Provider 类型 | `provider.type` | 下拉选择：`chat` / `kemo` |
| 模型 | `provider.model` | 文本输入，自由填写 |
| Base URL | `provider.base_url` | 文本输入 |
| API Key | `provider.api_key` | 密码输入框，已保存时脱敏显示 `***`，不修改不覆盖 |
| 流式输出 | `provider.stream` | 开关 |

### 多模态模型

折叠面板，每项一个文本输入框，留空表示不使用该能力：

| 标签 | 字段 |
|------|------|
| 图片识别 | `multimodal_models.vision` |
| 图片生成 | `multimodal_models.image_generation` |
| 图片编辑 | `multimodal_models.image_edit` |
| 语音识别 | `multimodal_models.audio_transcription` |
| 语音生成 | `multimodal_models.speech_generation` |
| 语音生语音 | `multimodal_models.speech_to_speech` |
| 视频生成 | `multimodal_models.video_generation` |

---

## 3. 用户切换

> 前端逻辑，不落配置文件

| 控件 | 说明 |
|------|------|
| 当前用户 | 只读展示 |
| 可切换用户 | 下拉列表选择 |

---

## 4. 记忆与上下文

> 📄 来源：`global_config.json` → `agents` + `memory.temporary_injection_limits`

只放与上下文窗口和记忆容量直接相关的字段。

### 上下文窗口

| 控件 | 对应字段 | 类型 |
|------|---------|------|
| Token 上限 | `agents.token_limit` | 数字输入 |
| Token 压缩比例 | `agents.token_compression_ratio` | 滑块或数字（0.0~1.0） |
| 最大对话轮次 | `agents.max_rounds` | 数字输入 |
| 压缩后保留轮次 | `agents.rounds_after_compression` | 数字输入 |

### 记忆注入上限（按文件数量截断）

| 控件 | 对应字段 | 类型 |
|------|---------|------|
| 周记忆上限 | `memory.temporary_injection_limits.seven_days` | 数字输入 |
| 月记忆上限 | `memory.temporary_injection_limits.one_month` | 数字输入 |
| 半年记忆上限 | `memory.temporary_injection_limits.half_year` | 数字输入 |

> `prompt.injection_mode` 和 `prompt.char_limits` 为底层注入策略，不在 Web UI 暴露。

---

## 5. 权限边界

> 📄 来源：`user_config.json`（白名单 + 开关）+ `global_config.json`（kemo_graph 底层开关）
>
> 统一管"能用什么"——技能、拓展、感知、插件、知识库、知识图谱。

### 知识库开关

| 控件 | 对应字段 | 来源 |
|------|---------|------|
| 使用共享知识库 | `knowledge.use_shared` | user |
| 使用全局知识库 | `knowledge.use_global` | user |

### 知识图谱（用户级）

> 控制检索后端是否使用知识图谱

| 控件 | 对应字段 | 来源 |
|------|---------|------|
| 图谱-全局知识库 | `kemo_graph.kemo_graph_global_knowledge` | user |
| 图谱-共享知识库 | `kemo_graph.kemo_graph_shared_knowledge` | user |
| 图谱-用户知识库 | `kemo_graph.kemo_graph_user_knowledge` | user |
| 图谱-临时记忆 | `kemo_graph.kemo_graph_temporary_memory` | user |

### 知识图谱（全局底层）

> 说明文字：*"底层控制——决定用户目录是否实际生成图谱数据。关闭后即使用户级开关打开也不生效。"*

| 控件 | 对应字段 | 来源 |
|------|---------|------|
| 图谱-全局知识库 | `kemo_graph.kemo_graph_global_knowledge` | global |
| 图谱-共享知识库 | `kemo_graph.kemo_graph_shared_knowledge` | global |
| 图谱-用户知识库 | `kemo_graph.kemo_graph_user_knowledge` | global |
| 图谱-临时记忆 | `kemo_graph.kemo_graph_temporary_memory` | global |

### 白名单

| 控件 | 对应字段 | 类型 |
|------|---------|------|
| 共享技能白名单 | `skills.shared_whitelist` | 标签输入（数组） |
| 共享拓展白名单 | `expand.shared_whitelist` | 标签输入 |
| 全局拓展白名单 | `expand.global_whitelist` | 标签输入 |
| 全局感知白名单 | `perception.global_whitelist` | 标签输入 |
| 插件白名单 | `plugins.whitelist` | 标签输入 |

---

## 6. 运行限制

> 📄 来源：`global_config.json` → `tools` + `history` + `task_plan` + `cron` + `agent_runtime`，以及 `user_config.json` 的 `task_plan.auto_accept`
>
> 统一管"怎么运行"——超时、次数、失败上限、步骤上限。

### 工具执行

| 控件 | 对应字段 | 来源 | 类型 |
|------|---------|------|------|
| 工具调用超时(秒) | `tools.timeout` | global | 数字输入 |
| 每轮最大工具调用 | `tools.max_iterations` | global | 数字输入 |
| 连续工具失败上限 | `history.consecutive_tool_fail_limit` | global | 数字输入 |

### 任务计划

| 控件 | 对应字段 | 来源 | 类型 |
|------|---------|------|------|
| 自动接受任务计划 | `task_plan.auto_accept` | user | 开关 |
| 任务计划最大步骤 | `task_plan.max_steps` | global | 数字输入 |

### 调度与超时

| 控件 | 对应字段 | 来源 | 类型 |
|------|---------|------|------|
| Cron 轮询间隔(秒) | `cron.poll_interval` | global | 数字输入 |
| 代理默认超时(秒) | `agent_runtime.default_timeout` | global | 数字输入 |

---

## 设计原则

| 栏目 | 一句话 | 存储 |
|------|--------|------|
| 外观与主题 | 长什么样 | localStorage |
| 模型与 Provider | 接哪个模型 | user_config |
| 用户切换 | 以谁的身份用 | 前端逻辑 |
| 记忆与上下文 | 记多少、窗口多大 | global_config |
| 权限边界 | 能用什么 | user_config + global_config（kemo_graph 底层） |
| 运行限制 | 怎么运行 | global_config + user_config（auto_accept） |

## 已删除的旧栏目

- **Prompt 与 Expand**：prompt 注入模式和 expand 数据配置过于底层，不在 Web UI 暴露。
- **配置文件 JSON**：原始 JSON 编辑器不再保留，所有配置通过上述结构化表单编辑。
