# 定时任务模板说明

复制 `cron_template.json` 并重命名为 `<task_id>.json`，放入 `users/<name>/task_cron/` 目录。

## 字段说明

| 字段 | 说明 | 必填 |
|------|------|------|
| `task_id` | 全局唯一任务 ID，格式 `cron_xxxxxxxx` | ✅ |
| `title` | 任务名称 | ✅ |
| `prompt` | 执行时发给智能体的提示词 | ✅ |
| `user` | 创建此任务的用户名 | ✅ |
| `type` | `daily`（每日）/ `once`（单次）/ `recurring`（重复） | ✅ |
| `next_run_at` | 下次执行时间，ISO 8601 格式，含 +08:00 时区 | ✅ |
| `latest_run_at` | 最近执行时间，未执行时为空 | 不改 |
| `status` | `pending` / `running` / `completed` / `failed` | 不改 |
| `created_at` | 创建时间 | ✅ |

## type 说明

- `daily`：每天固定时刻执行，`next_run_at` 只需时间部分有效
- `once`：只执行一次，到期后自动标记 `completed`
- `recurring`：每隔固定时间重复，执行后自动计算下次 `next_run_at`

## 调度

cron 模块每 30 秒扫描 `task_cron/` 目录，发现 `next_run_at` 到达的任务后调用智能体执行 `prompt`。
