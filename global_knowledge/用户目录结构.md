# 用户目录结构

kemo-agent 用户目录骨架、各子目录职责、初始化机制和配置字段说明。

更新时间：2026-07-18

## 目录骨架

每个用户目录位于 `users/<name>/`，由 `users/_template/` 复制创建。

```
users/<name>/
├── agents/                    # 当前用户的数据型热插拔子代理
│   └── <agent>/
│       ├── AGENT.md           # 子代理系统指令
│       ├── agent.json         # schema v2：元数据、输入输出、执行策略
│       └── agent-config.json  # 工具、技能、拓展、知识和公开范围白名单
├── avatar/                    # 用户头像
├── download/                  # 智能体生成的产物（图片、音频、视频、导出文件等）
├── expand/
│   └── <module>/inject.md     # 约定式用户拓展；按当前用户动态解析
├── file_upload/               # 用户上传的附件和外部文件
├── history/                   # 双层对话历史，按 source + session_id 隔离
│   ├── <timestamp>-<uuid>/    # 用户可见完整归档，无轮次上限、不可裁剪
│   │   ├── data.json          # 纯对话元数据，不含 context/summary 工作日志
│   │   ├── text.json          # 完整 user/assistant 对话文本
│   │   ├── think.json         # 完整原始 reasoning 记录
│   │   ├── tool.json          # 完整原始工具调用记录
│   │   └── items.json         # Kemo Provider 原生 Item 历史
│   └── temp/<timestamp>-<uuid>/ # Provider 临时工作区，受 agents.max_rounds 限制
│       ├── data.json          # 可额外保存 context 统计和 round_offset
│       ├── text.json          # 最近工作轮次
│       ├── think.json         # 可压缩 reasoning
│       ├── tool.json          # 可压缩工具调用
│       ├── items.json         # 最近工作 Item
│       └── context_summary.json # 被移除轮次的摘要缓存（按需生成）
├── improve/                   # 文件型记忆分层存储，schema v2
│   ├── storage.json           # 存储格式版本
│   ├── seven_days/            # Markdown 正文 + 轻量 data.json
│   ├── one_month/             # Markdown 正文 + 轻量 data.json
│   ├── half_year/             # Markdown 正文 + 轻量 data.json
│   └── permanent/            # 纯 Markdown，无 data.json
├── knowledge/                 # 用户私有知识库
│   └── data_structure.md      # 用户知识库索引
├── task_cron/                 # 用户的定时任务文件
├── task_plan/                 # 用户的任务计划文件
├── user_skills/               # 用户自定义技能（指令型，仅提示词注入，无工具调用）
│   ├── agent_create/          # 预留：子代理创建相关技能
│   ├── user_create/           # 预留：用户创建相关技能
│   └── <skill>/SKILL.md       # 约定式用户技能；按当前用户动态解析
├── memory_temporary_important.md  # 临时重要记忆（独立文件，注入 prompt，有字符上限）
├── user_config.json           # 用户配置文件（覆盖全局配置）
└── user_soul.md               # 用户人格文件（注入 prompt 第一层）
```

## 初始化机制

- `run/users.py` 的 `ensure_user(user, root)` 负责创建新用户。
- 验证用户名合法性（禁止 `_template`、特殊字符、点号开头）。
- 从 `users/_template/` 整目录复制到 `users/<name>/`。
- `write_json_if_empty()` 可在空文件时写入默认值。

## 配置文件 user_config.json

用户配置通过 `deep_merge` 覆盖 `config/global_config.json` 的全局默认值。

### 当前字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `schema_version` | int | 配置文件结构版本号，当前固定为 1 |
| `provider` | object | LLM 提供商配置，见下表 |
| `multimodal_models` | object | 多模态模型名（设计预留，源码尚未读取） |
| `task_plan` | object | 任务计划配置 |
| `skills` | object | 主智能体共享/用户 Prompt 技能白名单 |
| `expand` | object | 主智能体全局/共享拓展白名单 |
| `perception` | object | 主智能体全局感知模块白名单 |
| `knowledge` | object | 知识库开关与配置 |
| `kemo_graph` | object | 独立知识图谱连接请求状态（当前仅占位） |

### provider 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `type` | string | `"chat"` 或 `"kemo"`；不进行运行时协议回退 |
| `base_url` | string | API 地址；chat 自动补全 `/v1`，kemo 保持协议根地址 |
| `api_key` | string | 用户独立密钥（优先读取）；为空时读环境变量兜底 |
| `api_key_env` | string | 环境变量名（兜底用），kemo 默认 `KEMO_API_KEY`，chat 默认 `OPENAI_API_KEY` |
| `model` | string | 主对话模型名 |
| `stream` | bool | 是否流式输出 |

### multimodal_models 子字段（设计预留，源码尚未读取）

| 字段 | 说明 |
|------|------|
| `vision` | 图片分析/OCR 模型 |
| `image_generation` | 文生图模型 |
| `image_edit` | 图生图/局部重绘模型 |
| `audio_transcription` | 语音转文字模型 |
| `speech_generation` | 文生语音模型 |
| `speech_to_speech` | 语音转语音模型 |
| `video_generation` | 视频生成模型 |

不含 embedding 和 rerank（明确不做）。

### task_plan 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `auto_accept` | bool | 是否自动执行计划任务，默认 false |

### skills 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `shared_whitelist` | array | 共享技能白名单，空数组=全部允许，有内容=只允许列出的项 |
| `user_whitelist` | array | 用户技能白名单，空数组=全部允许，有内容=只允许列出的项 |

技能项使用相对于 `shared_skills/` 或 `users/<user>/user_skills/` 的目录 ID；嵌套技能示例为 `development/python`。仅过滤主智能体 Prompt，不改变技能注册，也不限制子代理。

### expand 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `shared_whitelist` | array | 共享拓展白名单，空数组=全部允许，有内容=只允许列出的项 |
| `global_whitelist` | array | 全局拓展白名单，空数组=全部允许，有内容=只允许列出的项 |

用户层 Expand 不使用这两个白名单，始终按当前用户的 `expand/<module>/inject.md` 动态解析。

### perception 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `global_whitelist` | array | 全局感知白名单，空数组=全部允许，有内容=只允许列出的项 |

白名单项是 `global_sense/` 的直接子目录名。每个直接子目录是一个模块，模块内部递归读取非隐藏 Markdown；根目录 Markdown 不注入。

### knowledge 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `enabled` | bool | 总开关；false 时知识索引、正文搜索和知识工具结果全部为空 |
| `use_shared` | bool | 是否使用共享知识库，默认 true |
| `use_global` | bool | 是否使用全局知识库，默认 true |

当 `enabled=true` 时，用户知识范围始终启用，再由 `use_shared` 与 `use_global` 决定是否加入共享/全局知识。`enabled=false` 优先级最高。

### kemo_graph 子字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `enabled` | bool | 是否请求连接独立项目 `E:\code\kemo-graph`；当前仅返回 `disabled`/`not_connected` 状态 |

当前版本不会启动子进程、不会调用图谱 CLI，也不会修改 kemo-graph 项目。

## 记忆分层

4 个挡位存储在 `improve/` 下。临时三层以独立 Markdown 保存正文，`data.json` 只保存文件名、weight、updated_at、last_weight_date 和 expires_at；永久层只有 Markdown：

| 挡位 | 有效期 | 晋升阈值 | 升级目标 |
|------|--------|----------|---------|
| `seven_days` | 7 天 | 权重 ≥ 3 | `one_month` |
| `one_month` | 30 天 | 权重 ≥ 10 | `half_year` |
| `half_year` | 180 天 | 权重 ≥ 60 | `permanent` |
| `permanent` | 永不过期 | — | — |

- 文件名是全层级唯一身份，基础名称最长 20 字；同名写入更新原记忆。
- 不做每日权重衰减；正文修改或成功注入使用时可加权。
- 修改和引用共用每日锁，同一记忆每天合计最多加权一次。
- `expires_at` 在进入层级时固定，引用和修改不会续期。
- 到期未达晋升阈值直接删除，不降级保留。
- 永久记忆全部注入；临时记忆只限制单次 Prompt 数量，不限制磁盘存储数量。

## 历史窗口

- 每个会话窗口是一个以 `<timestamp>-<uuid>` 命名的目录。
- 窗口内 4 个文件：`data.json`、`text.json`、`think.json`、`tool.json`。
- 路径硬编码为 `users/<name>/history/`，当前不支持配置自定义路径。
- `text.json` 和 `think.json` 和 `tool.json` 均有 `schema_version: 1`。
- `data.json.round_metrics` 按轮保存 Token、缓存命中、端到端耗时、工具调用数和运行中引导；旧窗口缺少该字段时按空列表兼容。
- `tool.json` 的调用记录包含后端单调时钟计算的 `elapsed_ms`。
- 仅 `data.json` 中 `complete: true` 的窗口可被历史搜索工具检索。

## 技能、拓展与子代理

- `user_skills/` 下的技能为指令型（仅注入提示词，不注册工具调用）。
- `expand/` 下每个直接子模块通过固定文件 `inject.md` 注入额外数据。
- 两者都由可信运行时按当前用户名解析，不使用用户目录中的 `register.py` 或 `registry.json`。
- 主智能体用户配置只在 Prompt 选择/知识检索阶段过滤；注册阶段仍保留完整库存。
- `agents/` 下每个直接子目录是一个 schema v2 数据型代理包；运行时每次发现和调用前重新扫描，新增、禁用或删除后无需重启。
- 用户代理只能使用通用 `builtin:llm` 执行器，目录内禁止 Python 文件，也不能覆盖内置代理名称。
- 主智能体通过 `subagent_dispatch` 插件列出、创建、调用和管理当前用户公开的子代理。
- 子代理授权与主智能体用户配置完全独立，只读取各自 `agent-config.json`；主智能体关闭来源不会压缩子代理权限。
- `agent_create/` 和 `user_create/` 当前仍为空目录预留。

## 用户名规则

- 不可包含 `\ / : * ? " < > |` 和控制字符。
- 不可以点号开头。
- 保留名 `_template` 禁止使用。
- 最大长度 64 字符。
