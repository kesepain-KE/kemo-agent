# 入口文件

**状态**：✅ 第七轮：7 个任务计划 CLI 命令

## 新增 CLI 命令

| 命令 | 说明 |
|------|------|
| `/plans` | 列出所有计划（ID/状态/进度/标题） |
| `/plan <目标>` | 生成计划并落盘（含步骤详情） |
| `/plan-show <ID>` | 查看计划详情（步骤/状态/依赖/关键性） |
| `/plan-approve <ID>` | 批准并立即执行（显示每步进度） |
| `/plan-pause <ID>` | 暂停运行中的计划 |
| `/plan-resume <ID>` | 恢复暂停的计划并继续执行 |
| `/plan-cancel <ID>` | 取消计划 |

### /plan 输出示例

```
已创建计划：plan_a1b2c3d4 | 下载并分析数据 | 3 步 | 状态：pending
  step_1 | download_direct_file | deps=无 | 下载文件
  step_2 | vision_analyze | deps=step_1 | 分析图片
  step_3 | write_file | deps=step_2 | 保存结果
使用 /plan-approve 批准执行。
```

### /plan-approve 输出示例

```
已批准计划 plan_a1b2c3d4，开始执行...
  [step_1] 开始：download_direct_file
  [step_1] completed
  [step_2] 开始：vision_analyze
  [step_2] completed
  [step_3] 开始：write_file
  [step_3] completed
计划 plan_a1b2c3d4 → completed
```
