# 环境变量 .env

kemo-agent 环境变量配置说明。`.env` 是实际配置，`.env.example` 是初始化模板。

更新时间：2026-07-19

---

## 配置优先级

```
user_config.json（最高）
    ↓ 未配置
.env 环境变量
    ↓ 未配置或不适用
global_config.json
    ↓ 未配置
源码硬编码默认值（最低）
```

---

## 变量全表

### Provider 密钥（兜底层）

| 变量 | 说明 | 当前值/默认值 |
|------|------|--------------|
| `KEMO_API_KEY` | Kemo 网关 API Key。`user_config.json` 的 `provider.api_key` 优先，空时读此变量 | `sk-a667...` |
| `KEMO_BASE_URL` | Kemo Provider 协议根地址。留空默认 `127.0.0.1:8741` | `http://127.0.0.1:8741` |
| `KEMO_MODEL` | 兜底模型名。仅当 `user_config.json` 的 `provider.model` 为空时使用 | 空 |

### Chat Completions 兼容模式（`provider.type=chat` 时使用）

| 变量 | 说明 | 当前值/默认值 |
|------|------|--------------|
| `OPENAI_API_KEY` | OpenAI 或兼容 API 的 Key | `your-openai-api-key` |
| `OPENAI_MODEL` | 兜底模型名 | 空 |
| `OPENAI_BASE_URL` | API 端点，可改为 Azure/代理商中转地址 | `https://api.openai.com/v1` |

### 网络代理

| 变量 | 说明 | 当前值 |
|------|------|--------|
| `HTTP_PROXY` | HTTP 代理地址，留空直连 | 空 |
| `HTTPS_PROXY` | HTTPS 代理地址，留空直连 | 空 |

### 工具插件

| 变量 | 说明 | 当前值 |
|------|------|--------|
| `TAVILY_API_KEY` | Tavily 搜索引擎 API Key。为空时 `tavily_search` 插件不可用 | 空 |

### Web 服务

| 变量 | 说明 | 当前值 |
|------|------|--------|
| `WEB_HOST` | 监听地址。`127.0.0.1`=仅本机，`0.0.0.0`=暴露局域网 | `127.0.0.1` |
| `WEB_PORT` | 监听端口。冲突时自动轮询下一个（最多 10 次） | `1357` |
| `WEB_ACCESS_TOKEN` | 访问令牌。非空时需在 URL 后带 `?token=xxxx` 访问 | 空 |
| `WEB_USERNAME` | 该智能体使用者的登录用户名。与内部多用户设计无关 | 空 |
| `WEB_PASSWORD` | 该智能体使用者的登录密码。与内部多用户设计无关 | 空 |
| `WEB_SESSION_SECRET` | Session 签名密钥。留空时自动生成，默认有效期 2 小时 | 空 |
| `WEB_SESSION_COOKIE_NAME` | Session Cookie 名称。多实例部署时各实例用不同名称 | `kemo_agent_session` |

## API Key 取值顺序

```
user_config.json 的 provider.api_key（明文，最高优先级）
    ↓ 为空时回退
KEMO_API_KEY / OPENAI_API_KEY 环境变量（按 provider.type 选择）
    ↓ 都为空时
报错：无可用 API Key
```

---

## Web 认证方式

Web 页面支持两种认证方式，可同时启用：

1. **Token 鉴权**：`WEB_ACCESS_TOKEN` 非空时生效，URL 后加 `?token=xxxx`
2. **账号密码登录**：`WEB_USERNAME` + `WEB_PASSWORD` 同时非空时生效

Session 有效期 2 小时，过期需重新登录。
