# 原理：系统提示词拼接 — 已废弃

> **此笔记描述的是旧版 `build_system_prompt()` 的 6 段拼接逻辑，已不再适用。**
>
> 当前系统提示词已经升级为 14 段的 `PromptBundle` 编排管线。
> 请参阅 [[原理-PromptBundle编排]] 获取最新信息。

## 主要差异

| 方面 | 旧版（本笔记） | 新版（PromptBundle） |
|------|---------------|---------------------|
| 入口函数 | `build_system_prompt()` | `build_prompt_bundle()` |
| 段数 | 6 段 | 14 段 |
| 记忆注入 | 运行时参数 `memory_text` | 分档注入 permanent + temporary_memory × 3 |
| 知识注入 | 运行时参数 `knowledge_text` | `knowledge_index` 专用段 |
| 工具来源 | 无专用段 | `plugins` + `skills` 两个段 |
| 扩展/感知 | 无 | `expand_data` + `perception` 两个段 |
| 任务计划 | 无 | `task_plan` 段 |
| 返回类型 | 纯字符串 | `PromptBundle` 结构化对象 |
| 诊断信息 | 无 | 完整的 sections/diagnostics/memory_files |
