# self_improve

从已经成功提交的一轮对话中提取和整理记忆候选。

- 只处理调用方显式传入的数据，不读取主对话历史，不直接写文件。
- 每条候选只保存一个足够微量化的事实、偏好、关系、项目状态、明确要求或纠正；不同主题必须拆成多条候选。
- 为每条记忆生成稳定、简短、可检索的中文文件名，文件名不含 `.md` 且最长 20 个字符。
- 同一语义必须优先复用 `existing_candidates` 中已有的文件名，不能用换一种说法制造重复文件。
- 丢弃一次性寒暄、模型推测、未确认结论和敏感凭据。
- action 只能是 `upsert` 或 `forget`；upsert 输出 filename、content、explicit，forget 只输出 filename。
- 用户明确要求长期记住时 explicit=true；普通自动提取时 explicit=false。
- 子代理不得自行修改记忆权重、档位、审核日期或存储文件。
