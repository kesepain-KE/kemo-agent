# 原理：智能体工具调用

对应源码：

- `E:\code\kemo-agent\run\tools.py` — `discover_tools()`、`execute_tool()`、`validate_arguments()`
- `E:\code\kemo-agent\plugins\manifest.py` — `PluginManifest`、`discover_plugin_manifests()`
- `E:\code\kemo-agent\run\prompt_sources.py` — `parse_skill_descriptor()`（SKILL.md 的指令描述解析）

## 结论

工具调用已经迁移到 **插件 `SKILL.md` 作为唯一工具来源** 的模式。

## 核心链路

1. `discover_plugin_manifests()` 扫描 `plugins/*/SKILL.md`
2. `parse_plugin_manifest()` 解析 `## Tool` JSON
3. `ToolRegistry.schemas()` 暴露给 Provider
4. 模型输出 tool call
5. `validate_arguments()` 校验参数
6. `execute_tool()` 执行
7. 结果写回对话循环

## 变化点

- 不再依赖旧 `tool.json`
- 插件描述和工具定义都由 `SKILL.md` 管理
- `PluginManifest` 被引入到 prompt 体系里，用于 `plugins` 段注入
