# 前端约定与调试

本文记录 `web/frontend/` 的样式组织约定，以及在真实返工中确认有效的调试方法。手册只保留
「UI 调试先量再改」的入口，具体手法在这里。

## 当前 UI 唯一入口与防回退（2026-10-26）

- 用户确认的新版界面是 `src/reference/` 及其主题链；技术迁移不得用仓库中遗留的另一套页面
  代替当前 UI，版本号相同、类型检查通过和页面无报错均不代表视觉与交互一致。
- `npm run check:ui` 在构建前检查十条业务路由及废弃文件；构建后 `--dist` 检查旧页面 chunk
  不再进入产物。`router.production.test.tsx` 逐条核验真正 lazy 入口，不能仅渲染脱离生产的页面。
- 源码实例为 `E:\code\kemo-agent` / 1357；`D:\kemo-agent` / 1457 是独立部署预览版。
  修复或构建源码不授权覆盖、重启或清理部署版。历史备份和用户数据不属于旧 UI 删除范围。
- 后续若改为声明式 React，须逐页保留当前 UI 与功能并进行桌面/移动端、明暗主题对照验收；
  不能直接接回已退役的旧页面。HTTP/Zod 契约、安全处理和已有业务修复继续保留。

## 请求错误、语音生命周期与共享历史命名

- `src/api/transport.ts` 校验错误回执中的 message/code 类型；空白、非字符串或非 JSON
  错误回执使用 HTTP 状态兜底，不把任意对象转成用户错误信息。仅 401 且 code 明确为
  authentication_required 时触发认证事件；成功 JSON 仍须通过已注册端点契约。
- `src/hooks/useSpeechRecognition.ts` 在错误、启动失败或卸载时解除回调并释放旧实例。
  错误后不依赖浏览器额外发送 onend 才能重启；旧实例迟到回调不能修改新实例或输入草稿。
  用户 stop 后仍允许当前实例交付最后的识别文字，直到正常 onend。
- 历史抽屉和只读归档的会话名称使用 `src/utils/sessionDisplayName.ts`；
  不为了一个工具函数导入已无渲染入口的旧面板，也不因此接回旧 UI。
  无引用文件仍须按删除清单确认，不顺带删除生产 reference 实现。

## 保存当前对话并新建

- 保存操作必须确认关闭接口返回 `closed=true` 后才新建。HTTP 200 不等于会话已经关闭；
  `closed=false/deferred=true` 表示其他页面或客户端仍在使用，此时不启动本次关闭的后台任务。
  前端保留原会话与草稿，显示原因并允许重试，不能直接跳到空白新对话造成“提取已启动”的错觉。
- 保存期间临时解除 URL 绑定，关闭被拒绝后恢复原空间时，错误提示随原 user/session 保留，
  不能被草稿恢复触发的空间重置清掉；真正进入其他空间或切换用户后清除，不跨空间泄漏提示。
- 页面异常退出的持久在线租约按既有 90 秒有效期自然过期，不强行清除其他页面的租约。
  正常 pagehide/切换则携带递增 lease_sequence，以 keepalive 有序释放自己的持久租约；
  pagehide 后停止续租，pageshow/online 用更大序号恢复，迟到请求不能覆盖新状态。
  每文档独立身份，复制标签页不会共享 client_id。关闭被真正其他页面阻挡时，
  使用 active_clients/retry_after_seconds 显示有效占用数与预计过期上界，不泄漏客户端身份。
  正常关闭后，记忆和摘要分别持久入队、唤醒对应 worker；请求本身不等待模型执行，
  也不把“已入队”显示成“已完成”。此流程与 Chat/Kemo 的协议选择无关。

普通本地非串行 LLM 子代理默认后台派发，显式同步合同不变。子代理工具卡在 ledger
尚无记录时显示“等待提交”；有记录后只按任务真实状态显示排队/执行/终态。
同会话多张卡共享列表发现请求，查询错误不显示假运行；新增状态反馈覆盖现有九种语言。

## 历史对话置顶、收藏与操作菜单

- 历史抽屉与侧栏最近对话共用 `SessionActions`。右键不打开/切换会话；每行同时提供常显 `⋯`
  以支持触屏。菜单顺序为置顶/取消置顶、收藏/取消收藏、分隔、重命名、打开、分隔、删除。
  只读来源的重命名/删除禁用，标记与只读打开仍可用；删除必须二次确认。
- 菜单 portal 到 body，不受滚动区裁切；在视口边缘向内避让，短窗口可内部滚动；
  支持上下键/Home/End、Escape、Tab 与外部点击。Escape 先收起菜单/本层编辑确认，不穿透关闭历史抽屉。
  重命名 1～80 字，失败保留草稿、提示可重试；请求期间阻止重复提交。
- 日期入口下方独立“☆ 收藏”气泡，显示服务端全用户收藏数量，选中高亮。
  进入收藏清除旧日期，之后可以再选日期，并叠加搜索；取消收藏筛选不修改任何记录。
  空收藏仍可明确确认删除全部历史，确认说明包括置顶/收藏及未加载、只读记录，不受筛选限制。
- 搜索输入只保存草稿，由右侧放大镜或 Enter 提交到服务端；清空恢复无关键词列表。
  不再用前端标题过滤剔除服务端命中的正文记录，输入期间不发请求也不丢焦点。
- 搜索框固定装饰图标、输入、清除占位和提交按钮四列；清除按钮显隐不能推动右侧放大镜。
- 标记显示小型 pin/star 图标，不挤压标题和来源；侧栏与抽屉标记、重命名同步。
  新控件接九语言目录，用户标题保持原文。存储/游标及权限合同见 `storage-and-persistence.md`。

## 右侧多标签工作面板

- 智能体任务按真实主任务分组：每个主任务独立圆角边框、浅底任务头、短 ID 与时间，
  主任务说明保留原文；所属子智能体放在同一容器内，以缩进、连接线和独立子卡片区分层次。
  相邻主任务之间保留间距，不把相同时间或同名代理跨主任务合并；沿用提交顺序与详情点击行为。
  没有子任务时不渲染空子列表，截断列表仍显示已加载数/总数；明暗主题与窄屏使用现有变量链。
- 面板新增“智能体任务”入口，展示当前会话主任务树与独立子任务详情标签；
  聊天中的简洁分派卡提供“查看执行”，不再渲染旧子代理工具卡旁的进度浮卡。
  不把 queued 回执当作子任务完成，不自动抢占当前标签；公开时间线、产物预览、
  有界结果、轮询及生命周期合同见 `agent-task-coordination.md`。
- 首次从顶栏展开工作面板时显示可编辑“草稿本”，不自动查询 Shell 作业；用户明确打开
  Shell 后台任务、智能体任务、文件预览或具体记录后才显示相应内容。
  Shell 列表固定限定为当前 Web 对话空间，不提供全用户/当前会话范围切换；
  未绑定会话时不发起列表请求。文件空间、聊天附件、输出产物和当前对话文件历史提供“在工作面板打开”。
  `shell` 工具结果含合法 `job_id` 时显示“查看后台任务”，只在用户点击后打开。
- 不提供“实例终端”入口。`src/components/workspace/` 按布局、任务和输出查看器拆分，
  `src/store/workspace.ts` 按用户维护内存标签，不把输出写入 localStorage。
  同一资源去重，最多 16 个标签，达到上限提示先关闭，不静默丢弃；支持固定、关闭、
  收起、最大化和拖动/键盘调宽。关闭只改变视图，绝不能取消作业或聊天运行。
- 桌面工作区可用宽度达到 1000px 时并排显示，面板 360～800px，聊天至少保留 540px；
  更窄时使用覆盖内容区的抽屉，提供焦点约束、Escape 收起和焦点恢复。
  标签支持左右/Home/End 导航，主题、背景透明度和毛玻璃继承用户设置。
  切页保留工作面板；切标签保留预览和搜索/滚动状态，隐藏媒体暂停，隐藏输出停止轮询。
- 文件预览复用 `FilePreview` 的有界读取、本机 Office 转 PDF、图片/音视频/Markdown/代码预览。
  文件空间已有详情与工作面板避免双栏叠加，面板打开时点文件名直接打开对应标签；
  从文件历史打开预览后收起原弹层。不把 HTML 源码当作可执行网页注入。
- Shell 后台任务使用独立只读接口：
  `GET /api/users/{user}/workspace/jobs` 和 `.../jobs/{job_id}`。
  前者支持 `session_id/source/page/page_size`，后者支持会话/来源精确约束；
  只读取当前用户 `runtime/background_jobs`，不扫描任意 PID、不提供命令输入/取消接口。
- 每个终端任务使用独立边框、圆角、底色和卡片间距；列表展示短标题、任务 ID、
  主任务/子代理归属、PID、工作目录、开始/完成时间、耗时及退出码。
  新通知尚未被模型接受处理时显示“待智能体处理”，不把网页打开当作模型确认。
  列表和运行态详情每 2 秒刷新，仅在对应标签可见时进行；
  详情结束或读取失败后停自动刷新，提供手动重试。stdout/stderr 分组显示，不虚构时间顺序。
  每流最多读取末尾 64 KiB、渲染最近 1000 行，截断时明确提示；支持搜索、复制和暂停跟随。
  输出以文本渲染并去除终端控制序列，不解释 HTML。
- 任务 GET 不调用 reconcile/cleanup/cancel，不读命令请求 sidecar，不信任记录中的日志路径。
  只读由合法 job_id 构造的普通独立文件，拒绝目录联接、符号链接、硬链接和不匹配用户记录，
  记录读取上限 128 KiB；响应 private/no-store。任务原始命令不额外保存或展示。
  worker 小量已 flush 的输出即时落盘；UTF-8 优先，必要时回退宿主 Shell 编码，
  正在写入的多字节尾部留待下次完整读取。

### 当前会话范围与默认草稿本

- 工作面板首次展开显示草稿本，不自动跳到后台 Shell。只有用户明确点击后台任务、智能体任务、
  文件预览或关联记录后，才打开相应标签；关闭标签不停止后台作业。
- Shell 列表查询固定携带当前非空 `session_id` 和 `source=web`，query key 包含用户、会话和分页；
  没有绑定会话时不查询，也不提供“此用户全部任务/当前对话任务”范围切换。
- 不在面板中展示实例终端；该页面只保留受管理后台 Shell 作业的只读详情。

### 草稿本与聊天交接

- `src/components/workspace/ScratchNote.tsx` 复用现有主题变量，编辑区内部滚动；
  顶部提供本机保存状态，底部提供字数、确认清空、放入聊天框和发送按钮。
  仅草稿文本按用户/对话空间保存在此浏览器 localStorage，不保存终端日志，不默认上传或跨设备同步。
  浏览器存储不可用/配额不足时保留内存内容并显示保存失败，不能谎称已保存。
- “放入聊天框”不自动发送；聊天框已有文字时必须明确选择追加/替换。
  “发送给智能体”由当前 ChatPage 注册作用域内入口，复用既有发送/下一轮排队，
  不新增直连模型接口，不带走聊天框未提交的附件，不清空聊天框已有文字。
  切页离开聊天路由后无发送入口时禁用直接发送；回到聊天后可继续。
- 普通 Enter 只换行；发送失败保留草稿，成功后仅清除已发送的 revision，
  不清除发送过程中新增的文字。关闭标签、收起面板、切换空间均不触发发送或清空。
  本机草稿与主聊天草稿分别维护，不建立两输入区互相覆盖的双向绑定。
- 后台 Shell 完成通知属于运行时能力，与网页是否展开/轮询无关。
  主/子代理收件、安全节点、确认及有界日志尾部见 `plugin-development.md`。

### 运行诊断的共享请求池

- 当前生产 `/status` 的“调度与维护”使用独立 `RuntimeCongestion` 组件，每 1.5 秒读取
  `runtime/status?sections=congestion`，不再等待整页 30 秒快照，不反复构建提示词或统计 Token。
  卡片原位更新占用、上限、可用与排队；失败保留上次成功值并提示，可手动重试，不伪装成 0。
- Provider 计数来自进程级共享信号量，主智能体与子智能体的真实模型请求共同计数；
  子任务执行工具、等待或已完成期间不占 Provider 槽位，“执行中的子智能体数”不等于模型并发数。
  页面明确提示这一口径，不用任务数量填充请求池，也不延长槽位占用来制造可见变化。
- 快照缓存键包含用户与会话；离开调度标签卸载并取消在途请求，切用户/会话不接收旧响应，
  页面在后台停止轮询、恢复前台重新读取；局部刷新不重建整页 DOM 或重置滚动。

### 原生媒体工具与相关文件联动

- `attach_media` 成功回执中的安全资产描述符实时进入顶栏“相关文件”的“工具装载的媒体”分组，
  同时在工具卡下显示文件名、装载状态和显式预览按钮。入口显示文件数量；
  按区域与相对路径去重，不与来源附件或输出产物重复计数。
- `media_input_update` SSE 事件更新当前轮工具媒体，终态 `done/error.metadata.media_inputs` 收敛状态；
  原始工具回执不被重写。`queued/prepared/included/failed` 与运行诊断保持同义。
  已结束但仍排队/准备的媒体显示“本轮未发送”；旧历史没有交付审计则显示“发送状态未确认”，
  不能仅因工具成功就声称已发给模型，也不能反过来断言旧请求从未发送。
- 历史接口在轮次指标和工具 trace 中返回 `media_inputs`，刷新后可恢复。
  旧版成功回执可通过同名且唯一的工具 `paths` 参数恢复当前用户受管理文件定位；
  失败工具或单独参数不能生成文件条目，不改写持久化历史。
- 只为当前用户 `download/file_upload` 的普通独立文件提供预览与下载。
  外部/其他用户/符号链接/目录联接只显示描述信息，缺失或大小变化文件禁用预览；
  文件实际读取继续经过现有文件服务的路径约束。图片缩略图复用用户历史中的小 WebP 缓存，
  `attachment-thumbnails` 默认仍为 `file_upload`，新增显式 `area=download`。
- 点击工具卡或相关文件中的预览，复用右侧工作面板的同资源标签，且收起文件浮层。
  不自动打开、不复制原媒体、不重新调用模型，也不自动引用到下一条消息。
  仅上传区文件保留“引用到输入框”；下载区文件不能伪装成上传附件。

## 网页多语言与用户隔离

- “配置 → 外观与主题”提供独立的语言选择，使用原生语言名；支持九种：
  `zh-CN`、`en`、`es`、`fr`、`de`、`pt-BR`、`ru`、`ja`、`ko`。
  老用户缺省简体中文，不按浏览器系统语言自动改写用户选择。
- 唯一权威配置是 `users/<name>/user_config.json` 的 `web_ui.language`；
  `GET preferences` 合并返回它，但 `PATCH preferences` 仅保存主题/字号，语言通过
  `PATCH /api/users/<user>/config` 的 `{changes:{web_ui:{language}}}` 单独保存。
  不写 `global_config.json`，也不在 `web_preferences.json` 建立第二份语言真值。
- 浏览器缓存键为 `kemo-language:<user>`。切换用户先切换该用户缓存，再由该用户 API
  校正；旧用户异步响应不能改变新用户当前语言。保存期间禁止重复选择；
  失败回滚原语言、缓存与 `html.lang/dir` 并显示错误。禁用 localStorage 不妨碍保存到服务端。
- 语言立即应用，不刷新或重挂载对话，不清空草稿、不取消运行。
  独立语言保存不触发整份 user-config 重新读取，以免覆盖未保存的模型配置草稿。
- `src/i18n/` 使用显式词条和 `{name}` 插值；React 通过 `useLanguage()` 订阅，
  第一方导航、外观页、常用动作与业务页通用控件显式调用 `t()`。
  未收录的详细帮助/专业配置文案回退原中文，不承诺现阶段所有文案均已翻译。
  新增 UI 文案应同步补齐八种译文；测试要求词条唯一、列数完整、插值变量一致。
- 禁止用 DOM 全局替换/翻译观察器，禁止把文件名、用户分类名、会话标题、知识/记忆正文、
  模型输出、日志原文或插件自带内容直接传给翻译器。即使它们恰好等于某个 UI 词条也保留原样。
  UI 语言不设置模型回复语言，也不改变 Prompt 组装规则。
- 阿拉伯语已移除；旧配置或浏览器缓存中的 `ar` 回退为简体中文，并重置
  `html dir=ltr`，不再使用右向左导航布局。不在读取时改写用户配置文件。
  API 拒绝显式保存 `ar`，但旧值不能阻碍启动或其他字段保存；详见配置参考。
- 语言选择窄屏占满可用宽度；保留长译文换行与移动导航按钮最小宽度。
  兼容高级白/高级黑，验收需实际检查长译文与 375px 窄屏。

## 用户网页背景

- “配置 → 外观与主题”在界面主题与字号之间提供独立背景卡片，包含预览、文件信息、
  启用开关、上传/更换、确认清除、重新读取、遮罩强度、背景模糊、UI 透明度和 UI 毛玻璃。
  UI 两项与动态背景在同一张卡片，不新增页面；窄屏预览与操作上下排列，
  按钮换行；新控件同步九种语言。关闭只停用显示，清除才删除当前用户的背景文件。
- 背景资源为 `users/<name>/background.*`，显示配置唯一存于
  `user_config.json → web_ui.background`，不能通过全局配置或 `PATCH preferences` 保存；
  配置详情见 `configuration-reference.md`，模板/复制边界见 `knowledge-and-user-data.md`。
- 新模板附带原创程序绘制的轻量 `background.webp`，新用户默认关闭；旧用户不自动补文件。
  JPG/JPEG、PNG、WebP 静态图片最大 100 MB、3200 万像素，不接受动图；
  MP4、WebM 视频最大 400 MB，必须通过容器结构与视频轨检查，实际解码仍由浏览器决定。
  前后端、模板验收与手工文件识别使用一致大小上限；容器遍历使用 memoryview，避免复制大载荷。
  不支持 SVG、任意本机路径或远程 URL；上传按内容识别格式并规范为固定名称。
- `GET /api/users/<user>/background/status` 返回当前用户资源元数据与显示配置；
  同路径 `/background` 的 POST/GET/DELETE 分别上传、读取、清除，均走现有 Web 认证。
  媒体 GET 支持字节 Range，并使用 private/no-store、nosniff 等响应头；
  不通过静态目录公开用户根目录。拒绝符号链接、目录联接、硬链接背景文件。
- 手工放入资源后用背景卡片“重新读取”发现；若有多个合法后缀，选最近修改的有效文件
  （同时间按名称稳定排序），不在读取时删除其他文件。成功上传替换当前受支持格式的背景；
  失败上传恢复旧资源。后台读取只做有界验证缓存，不把媒体内容常驻缓存。
- 公共 `AppBackground` 属于应用外壳，页面导航不重新创建视频；切换用户按用户键卸载旧背景，
  异步请求只更新原用户缓存，不闪现前一用户资源。背景配置保存不刷新整份模型草稿。
- 背景使用独立底层媒体与随主题变化的遮罩；启用后取消输入坞 `.composer-dock` 的整条主题色
  渐变底，不在聊天底部泛白/泛黑遮挡。UI 透明度只改变面板/侧栏/顶栏/对话气泡/输入框等现有
  主题底色的 alpha，不给整个应用设 opacity；代码与文字不模糊、不淡化，前景布局不变。
  UI 毛玻璃使用面板的 backdrop-filter，背景模糊仍单独作用于媒体；禁用背景时恢复原主题。
  UI 透明度拖动即时预览（0% 不透明，100% 全透），UI 毛玻璃 0～30px；点击应用保存，
  保存失败、离开设置或切用户均移除草稿预览并回到该用户持久配置，不改写 Provider 草稿。
- 视频启用后静音循环、内联播放，不读取或订阅 Windows/浏览器的减少动态效果偏好，不降为静帧。
  页面隐藏暂停，返回后尝试继续；切用户/停用/卸载才释放。自动播放被拒绝或解码失败时回退原主题，
  在设置页提示。等待媒体就绪用透明度隐藏图层，不用 visibility:hidden 阻碍浏览器媒体就绪。
  背景文件不进入知识库、聊天附件、模型请求或 Prompt。

## Web 访问认证布局

访问边界：未启用认证仅允许已确认的 loopback 客户端，缺失/非法客户端地址不当成本机。
代理头存在但未配可信代理时拒绝；可信 loopback 代理的 X-Forwarded-For/X-Real-IP
必须有效、一致且最终来源仍为本机；重复头、畸形链或 Forwarded 头拒绝免认证访问。
代理可能不传来源头，服务无法仅凭 HTTP 区分透明反代与本机请求，因此对外反代必须启用实例认证。
不无条件信任最左地址，不在应用层重复扩大 ASGI 服务器的代理信任范围；
`/api/auth/status` 保留公开 200，用于发现现有 Token/密码流程，不借隐藏端点替代认证。

- Token 与用户名/密码认证共用 `AuthLayout` 品牌区和安全提示，表单与加载/连接失败状态
  共用 `AuthPage.module.css`，认证前也应用本机缓存的高级白/高级黑主题和界面字号。
  认证内容固定最大 440px，
  品牌图标与名称紧邻居中，标题、说明、字段、错误与主按钮放在同一张卡片，避免旧布局的
  大面积留白与表单内重复卡片。使用独立 CSS Module，避免旧 reference 认证选择器串扰。
- 同时开启两种认证时，仅展示当前阶段的表单；卡片顶部标记“访问令牌 → 账号登录”两步，
  令牌通过后标记完成并将焦点交给用户名。单一认证不显示两步进度；仍由服务端 status.stage
  决定状态，不增加绕过或修改认证协议。
- Token 与密码默认隐藏，可通过有名称的按钮切换可见性；按钮不提交表单。
  切换阶段重新挂载表单，清除上一阶段的输入、显隐和错误状态。请求期间禁用输入和按钮，
  错误在当前表单内就近展示并关联到字段，修改输入后清除旧错误；保留 Enter 提交和密码管理器
  的 username/current-password 自动填充语义，不存储凭据，不从 URL 自动认证。
- 认证页使用独立 `100dvh` 滚动容器；手机、横屏、矮窗口与缩放后内容可正常滚动，
  不受全站 body overflow:hidden 裁切。输入字体至少 16px，窄屏不缩小点击区域。
  加载和服务不可用时沿用同一品牌与卡片，提供重新连接入口。

## 变量链断裂：最常见也最难察觉的失效

**症状**：样式改了但页面上看不出任何变化，元素既没有背景也没有预期颜色，文字回退成继承色。

**根因模式**：声明引用了只在某个容器类上定义的别名变量，而**那个类从未挂到 DOM 上**。
此时 `var(--xxx)` 解析为空值，**整条声明失效**（不是回退到默认值，而是整条作废）：

```css
.memoryPage { --memory-brand: var(--brand); }      /* 定义了别名 */
.lifecycleInline { background: color-mix(... var(--memory-brand) ...); }
/* 若 <ModuleFrame> 没有 className={styles.memoryPage}，上面这条 background 整条消失 */
```

**排查顺序**：

1. 搜该页面/组件的类是否真的被使用：`styles.<容器类>` 在 TSX 中出现几次（0 次即命中本问题）。
2. 搜变量的定义处与引用处数量是否匹配。
3. 用全仓扫描确认变量名是否根本不存于任何定义（近似名混淆也常见，如
   `--ink` / `--text-muted` / `--orange` / `--surface-1` / `--shadow-lg` 这类"想用但没定义"的名字）。
4. 若容器组件支持 `className` 透传（如 `ModuleFrame`），补上挂载即可一次性恢复全部引用。

**预防**：变量只在确定会被渲染的容器上定义；新增别名后立刻检查该容器是否已在用。

## 布局调试：投影被父容器裁切

**症状**：卡片四周只有一圈**方形**的阴影（不是柔和扩散），圆角处也被切直。

**根因**：卡片与外层容器**尺寸齐边**，而外层设了 `overflow: hidden`。
`box-shadow` 向外扩散的部分（偏移 + 模糊半径）落到容器边界之外，被整条切掉。

**确认方法**：用 DevTools 的元素高亮（盒模型叠加层）看 —— margin 区（橙色）四角是**直角**
而 padding 区（绿色）是圆角，就说明阴影被外层裁了。或者量 `getBoundingClientRect()`，
卡片底边与外层容器底边坐标完全重合即为齐边。

**修法**：让内容区在该模式下 `overflow: visible`（条件类，不影响其他模式），
或给卡片留出大于阴影扩散距离的间距。不要用 `margin-bottom` 硬挤 —— 那只会压缩卡片高度。

**输入坞对话菜单**：样例 `.composer` 的 `overflow: hidden` 会裁掉其内部向上展开的
`.conversation-menu`，提高菜单 z-index 不能突破父层裁切。生产适配使用
`.composer.composer-inner { overflow: visible; }`；菜单锚定整条 `.composer-bar` 而非操作按钮，
避免窄屏或停止按钮出现时弹窗左缘被挤出视口。菜单按视口限制高度并内部滚动，
不要为保留圆角重新给这层容器加裁切。验收必须实际打开菜单，检查上/中/下部命中菜单且所有操作可滚动到达，
不能只检查关闭状态或 DOM 中存在 `role=menu`。

## 滚动条

- CSS Module 里定义 `::-webkit-scrollbar` 不一定生效；还要处理 `::-webkit-scrollbar-button`
  （浏览器默认箭头按钮）与 `scrollbar-gutter`，否则会出现多余的轨道条或箭头。
- 出现"多出来一条方框"先确认是不是滚动条，再动样式。

## 改前端样式后的验证

1. **构建**：`npm run build`（含 `tsc -b` 类型检查）。
2. **产物核对**：在 `dist/assets/*.css` 里搜改后的规则名，确认编译结果与预期一致
   （有些写法在构建后会被改写或与相邻规则合并）。
3. **计算样式**：页面刷新后读 `getComputedStyle()`，确认目标属性真的生效，而不是只看源码。
4. **测试**：`npm test`（vitest）。涉及文案或 role/aria 的 DOM 变更要同步断言。
5. 浏览器可能缓存旧壳，验证前先强制刷新。服务端对 SPA `index.html` / 路由回退固定返回
   `no-store, no-cache, must-revalidate`，避免新构建继续引用旧哈希 Chunk；`dist/assets/` 的哈希产物则
   返回一年 `immutable` 缓存，其他静态文件使用 `no-cache`。改变这组规则时同步测试响应头。

## 文案与 DOM 契约

- 测试可能断言具体文案、`role`、`aria-label`。移动元素位置通常不影响按 role 查询的断言，
  但**改文案或删元素会**。改前先搜测试。
- 展示层剥离标点、缩短文案时，同步更新对应断言。
- 历史日期浮层通过 Portal 挂在 `document.body`，测试应从 `screen` 查询，不能限定到抽屉 DOM 内，否则会误报日历不存在。

## 新建对话的路由交接

保存新建或清空新建时，自动恢复旧会话应持续暂停，直到新会话 ID 已提交到 URL；
不能在创建接口返回时提前解除 `sessionTransitioning`，否则本地状态更新可能抢先于路由提交，
导致旧活跃会话恢复逻辑覆盖新会话地址。切换其他页面期间仍按最新页面位置更新参数，不强制返回聊天页。

### 新建与保存新建的延迟边界

- 新建接口已持久预留空间并写入本标签页租约。仅当回执同时确认 `created=true`、匹配的
  `user/client_id`、`active_clients>0` 和 Web/open 会话时，前端复用这个短时确认，
  立即绑定新地址和读取正文，不串行再等一次初始化 lease。确认只消费一次、最多有效 15 秒；
  后续 15 秒心跳、页面恢复与既有会话验证仍走真实 lease。旧服务缺少这些字段时继续验证，
  不能因浏览器缓存存在而跳过 closed/deleted 裁决。
- 同一用户、同一源空间的并发新建复用一个 Promise 和一个 POST；旧请求结束不能清除其他
  用户/空间的新建锁。创建成功把服务端返回的会话补入已有列表，不伪造尚未读取的完整库存。
- 未绑定空间期间不读取 overview、聊天任务与欢迎 Token 聚合；新 URL 自行读取新 overview，
  不再额外刷新旧/无绑定空间的概览。首次任务读取在计划列表为空时不重复失效已同时加载的正文；
  存在计划时仍重新核对正文，避免首屏加载期间任务刚完成却漏掉结果。后续任务轮询与运行提交仍刷新正文。
- 保存新建仍严格“关闭旧空间（持久登记后台记忆/摘要）→创建新空间”，不并行投机创建；
  同步防连点。新建成功才清理原草稿，失败保留草稿且不隐式恢复已关闭空间。
- 会话列表、正文、overview 和任务总览的同步服务调用在工作线程执行，避免较慢的磁盘读取
  或上下文计算阻塞 ASGI 事件循环，挤压新建/关闭请求。归档元数据和索引单行优化见
  `storage-and-persistence.md`；不通过降低 SQLite 持久化或省略保存来换取速度。

## 导航与最近会话恢复

- 所有业务导航携带当前 `user + session`，根路由与未知路由回跳聊天页时保留查询参数。
  首轮发送前必须通过会话接口预留并绑定空间，不能等任务终态再填写 URL；切页期间 Run 注册表、
  SSE 控制器、文本草稿和附件仍由 AppShell 与草稿 store 持有，不随聊天页面卸载而清除。
- `sessionNavigation.ts` 只缓存每用户最近空间的 ID：sessionStorage 保存本标签页身份，
  localStorage 保存前台最近访问身份。后台心跳不能抢占其他页面的最近空间。
  显式 URL 优先，其次本标签页、浏览器最近空间，最后既有后端 active-session 合同。
  缓存恢复前调用 lease 验证；404 清除对应缓存后回退，断网或 5xx 保留身份等待重试。
  不调用 reopen，也不复活 closed/deleted 记录；显式失效 URL 仍解除绑定并提示，不自动新建替代空间。
- 会话正文读取不依赖其是否在历史索引第一页；成功验证的会话可直接按 ID 分页读取正文。
  恢复刚预留的空会话同样绑定 URL 并刷新历史索引，避免缓存列表落后时一直停留无会话状态。
- 配置页重启后等待原端口健康检查成功，再整页加载 `/chat?user=...&session=...`。
  最多等待 60 秒，失败保留身份供重试；离开配置页取消等待，迟到健康响应不能改变当前页面。

## 知识库编辑与预览

- 知识库工具栏依次为搜索框、分类下拉选择器、“分类名输入框 + 新建分类按钮”三个区域，
  各控件统一为 40px 高，桌面端顶底对齐。分类下拉列出全部分类及文件数，包含全部分类和未分类；
  在“全部”层级中，分类选项以“用户层 / 共享层 / 全局层 · 分类名”标注来源，
  按各层分别列出分类与计数；同名分类和未分类都不跨层合并。筛选键同时绑定来源与分类名，
  单层视图只显示该层分类名，详情归类选择也只使用当前文件所属层的分类。
  切换层级时重置分类筛选。新建分类只保留输入框和按钮，选择文件后可创建分类并归类当前文件，

## 正文内联组件

- 聊天正文组件只通过 `kemo-widget` 声明渲染；内置类型走 `InlineWidget` 专用组件，未知声明式名称走
  通用数据卡。开放名称兼容不代表执行任意 HTML、JSX、脚本、样式文本或远程 iframe。
- 流式渲染必须先确认 fence 闭合。不能只依赖 `streaming=false`，因为失败重试快照也会把半截正文
  收口为静态消息；未闭合组件应显示占位或未完成状态，不显示原始 JSON。
- 新组件必须使用主题变量和 CSS Module，支持暗色主题、窄屏、键盘焦点与文本/表格替代；Tooltip
  不能是读取数据的唯一途径。
- 表格排序、筛选、分页、列显隐，标签页、折叠、轮播等状态只保存在组件本地，不另建持久化表。
- 历史归档抽屉对输入会话做防御性时间倒序，避免 mock、缓存合并或旧接口返回乱序；搜索框下方的日期入口以内联
  42 格月历展开，周一为每周起点，提供上月/下月、清除和今天，并禁用上海自然日之后的未来日期。选中日期后使用
  独立 `history-sessions` 查询缓存，不能把主 `sessions` 缓存替换为日期子集。
- 历史抽屉“全部删除”覆盖当前用户全部渠道，包含只读对话和分页未加载记录，不受搜索/日期筛选限制；
  按全渠道列表判断按钮可用性，不能因为 Web 条数为零而禁用。日期筛选为空也可确认删除全量历史。
  复用全局危险确认层：短范围标题明确“全部渠道 · 包含只读对话”，可换行正文说明不可撤销、
  不受筛选限制与记忆/附件/任务定义不删，不能把已加载条数当全部数量。只读卡片仍不能续聊或单条修改/删除。
  请求显式发送 `source=all` 及当前 `client_id`；409/异常保留确认框、会话绑定与缓存以便重试，
  成功才清理当前用户 `history/readonly-history/active-session` 缓存、最近会话绑定并刷新列表和概览；
  不清理其他用户缓存。后端事务、活动运行与租约保护见 `storage-and-persistence.md` 的“网页全部删除历史”。
- 需要进入会话的交互统一走 `InlineWidgetAction`，只允许 `fill-input|send-message|copy`；组件不得直接
  调 API、插件或任意回调。媒体 Schema 只接受以单个 `/` 开头的站内 URL。
- 组件字段或上限变化时同步更新 `inlineWidgetProtocol.ts` Schema、渲染组件、复制 fallback、定向测试
  以及 `global_knowledge/inline-widgets.md`。完整协议以该专题为准。

## 对话空间 Token 命中率

- 上下文窗口显示“Token 总命中率”，只读取当前 `user + source + session_id` 对话历史中
  持久化的累计用量；不复用运行状态页面的用户每日统计。
  首选该会话持久化的 `cache_hit_rate`，缺少时仅在该会话同时有缓存命中与未命中 Token 计数时计算。
- 当前会话无缓存数据、无可靠分母、会话未绑定或返回比例不在 0–1 时显示“—”，不能伪造为 0%。
  显示按当前网页语言格式化，并标注为当前对话空间累计。

## 当前 UI 与 HTTP 合同（2026-10-26 校正）

- tasks/runtime status/knowledge/memory 四类高频响应先经后端 response_model，再经前端 Zod。
  响应字段缺失是合同错误，不把 null 默默变成空库存；错误仅报告字段路径，不泄露响应内容。
  六类任务写 Body 在 service 副作用前严格校验，保持既有 invalid_request HTTP 400 错误合同。
- 认证、单条/批量会话删除、计划/Cron 写操作、清理预览/结果、工作面板任务与日志 JSON
  同样挂字段级 response_model。工作面板返回经验证的对象，保留 private/no-store 与 nosniff，
  不用直接 JSONResponse 绕开校验；可选缺省字段不额外注入 null，额外兼容字段仍保留。
  响应校验失败返回固定 500 错误，仅记录字段路径，不将被拒绝的业务载荷或凭据拼进错误；
  SSE、文件和媒体传输继续使用各自协议，不强套 JSON 模型。本轮不进行额外页面迁移。
- GET facade 支持 AbortSignal，React Query 传入 signal；切用户、标签或卸载取消旧读取。
  queryKey 必须绑定 user 和必要会话/选择范围。后台刷新不得覆盖正在编辑的正文草稿。
- 任务保留会话执行范围、历史 revision/CAS、结构化 Cron 编辑和 immutable cleanup 预览确认；
  单次时刻从 ISO 转上海墙上时间，提交只追加一次秒与 +08:00，保留多时刻和原状态。
- 子智能体/技能六条分页先筛选再切片，换页同步右侧选择，换分类/搜索回第一页。
  提示词正文与组件状态同屏；临时重要记忆只读，永久记忆不出现权重输入。
- 生产路由可达性、模块行为、真实后端 HTTP 和隔离浏览器检查互补，不能把仅测试死页面当验收。
  reference 是当前新版生产 UI，不是废弃样例或旧版兜底；不得重新接入已删除的旧业务页面。
