# 写盘优化专项测试

本目录验证高频采集、定时任务、对话历史和数据库迁移的写盘边界：

- 仅明确无变化成功省略逐次日志，变化成功与每次错误立即持久化，另有小时统计；
- 日志保留期按环境变量、实例配置、代码兜底读取，复用实例也在下次写入采用新策略；
- 系统任务运行时间在内存推进，只按检查点或关闭持久化；
- 感知/拓展模块只在语义内容或健康状态变化时替换文件；
- CardStream RAW 事件立即追加，VIEW 压缩、有效 Token 和摘要吸收关系原子提交；
- 当前 CardStream schema 升级先备份、事务回滚及未来版本拒绝；旧 history/window 文件不读取、不迁移、不删除。
