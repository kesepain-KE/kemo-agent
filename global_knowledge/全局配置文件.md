# 全局配置文件 global_config.json

kemo-agent 全局默认配置。所有用户的 `user_config.json` 通过 `deep_merge` 覆盖本文件中的同名字段。

更新时间：2026-07-19

---

## 覆盖规则

| 层级 | 优先级 | 说明 |
|------|--------|------|
| `user_config.json` | ✅ 最高 | 同名字段完整覆盖全局值 |
| `global_config.json` | 默认值基底 | 用户未配置时使用 |

`user_config.json` 中不存在的字段直接继承全局值。`deep_merge` 是整对象替换，不是逐字段合并——比如用户 `provider` 会完整替换全局 `provider`。

## 配置项全表

### tools — 工具调用控制

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `enabled` | `true` | 是否允许 AI 调用工具（function calling） |
| `timeout` | `240` | 每个工具的单次超时秒数。超时后该次调用失败，计入 `consecutive_tool_fail_limit` |
| `max_iterations` | `8` | 单轮对话中最大工具调用迭代次数（防止死循环硬上限） |
| `max_per_round` | `null` | 单轮对话最大工具调用次数；AI 回复最终文本前超过此数需用户手动点击继续。`null` = 不限制 |

### history — 对话历史

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `schema_version` | `1` | 历史存储结构版本 |
| `recent_full_rounds` | `3` | 最近 N 轮对话完整保留不做压缩 |
| `consecutive_tool_fail_limit` | `5` | 某个工具**连续失败**达到此次数后，提示智能体换思路，不再重复尝试该工具 |

### prompt — System Prompt 拼接

#### char_limits — 各模块注入字符上限

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `task_plan` | `6000` | 当前任务计划内容注入上限 |
| `perception` | `8000` | 感知模块数据注入上限 |
| `expand_data` | `10000` | 拓展模块注入上限 |
| `skill_prompts` | `8000` | 用户 Skill 提示词注入上限 |
| `plugin_prompts` | `10000` | 内置插件提示词注入上限 |

#### injection_mode — 各模块注入模式

所有模块当前均为 `"full"`（完整注入）。可选模式：

- `"full"` — 完整内容注入 prompt
- `"summary"` — 摘要注入
- `"disabled"` — 不注入

| 模块 | 模式 | 说明 |
|------|------|------|
| `permanent_memory` | `full` | 永久记忆 |
| `important_memory` | `full` | 重要记忆 |
| `temporary_seven_days` | `full` | 7 天档临时记忆 |
| `temporary_one_month` | `full` | 1 月档临时记忆 |
| `temporary_half_year` | `full` | 半年档临时记忆 |
| `knowledge_index` | `full` | 知识库索引 |
| `task_plan` | `full` | 当前任务计划 |
| `expand_data` | `full` | 拓展数据 |
| `perception` | `full` | 感知数据 |

### kemo_graph — 独立知识图谱

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `enabled` | `false` | 是否启用与 `E:\code\kemo-graph` 独立项目的连接请求。当前仅返回状态，不会启动子进程或调用图谱 CLI |

### memory — 记忆系统

#### storage_schema_version: 2
记忆存储结构版本。

#### temporary_injection_limits — 单次 Prompt 注入条数上限

| 挡位 | 当前值 | 说明 |
|------|--------|------|
| `half_year` | `300` | 半年档记忆单次最多注入 300 条 |
| `one_month` | `200` | 1 月档记忆单次最多注入 200 条 |
| `seven_days` | `100` | 7 天档记忆单次最多注入 100 条 |

> 仅限制单次 Prompt 注入数量，不限制磁盘存储总量。

#### important_memory_max_chars: 2000
重要记忆单条最大字符数。

#### history_read_enabled: true
是否允许智能体调用**查询历史对话的专用工具**。`false` 时智能体无法检索过往对话记录。

#### tiers — 记忆生命周期层级

| 挡位 | 有效期 | 升级阈值 | 升级目标 | 说明 |
|------|--------|----------|----------|------|
| `seven_days` | 7 天 | 权重 ≥ 3 | → `one_month` | 短期记忆，到期达标晋升 |
| `one_month` | 30 天 | 权重 ≥ 10 | → `half_year` | 中期记忆 |
| `half_year` | 180 天 | 权重 ≥ 60 | → `permanent`（后台自动处理） | 长期记忆，到期达标晋升永久 |

**晋升规则：**
- 每条记忆每自然日最多加权一次（修改和引用共用每日锁）
- 只有实际注入上下文才算有效引用
- 到期未达阈值 → 直接删除，不降级保留
- 永久记忆由后台自动处理，不在此配置中声明

### agent_runtime — 子智能体运行参数

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `queue_maxsize` | `0` | 子智能体队列最大大小。`0` = 不限制 |
| `default_timeout` | `600` | 子智能体默认超时秒数。超时后**不自动关闭子智能体**，而是要求主智能体去查看子智能体日志、判断其是否正常运行。最终是否关闭由主智能体决定 |

### task_plan — 任务计划

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `max_steps` | `20` | 单个任务计划的最大步骤数 |

### cron — 定时任务调度器

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `enabled` | `true` | 是否启用定时任务调度器。`false` 时所有定时任务不会触发 |
| `poll_interval` | `30` | 调度器每隔 **30 秒**检查一次是否有到期的定时任务需要执行 |

> 调度器默认随智能体启动自动开始，无需手动操作。

### runtime_host — 后台定时调度

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `enable_background_scheduler` | `true` | 智能体启动时自动开启后台定时调度。覆盖两类任务：① **cron 定时任务**（用户创建的定时提醒/执行）② **定时调度项目**（临时记忆处理、上下文整理等非用户自定义的周期性后台任务） |

### message — 消息路由

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `max_workers` | `8` | 消息处理线程数，同时处理外部消息的并发能力 |

> 账号绑定、传输层配置等路由参数在 `config/message_config.json` 中，本文件不参与。

### agents — 智能体运行时策略

| 字段 | 当前值 | 说明 |
|------|--------|------|
| `conserved_rounds` | `3` | 工具调用压缩前保留的最近完整轮次数 |
| `max_rounds` | `80` | 单次对话轮次上限 |
| `rounds_after_compression` | `20` | 触发压缩后保留的轮次数 |
| `token_limit` | `1000000` | Token 上限（触发压缩的阈值） |
| `token_compression_ratio` | `0.3` | 触发压缩时压缩至原 Token 数的比例（即压缩到 30%） |
| `important_memory_review_hours` | `3` | 重要记忆审阅间隔（小时） |
| `daily_memory_review_time` | `"02:00"` | 每日记忆审核触发时间（北京时间） |

## 已从全局配置中移除的项目

以下配置项已从 `global_config.json` 中移除，由其指定来源接管：

| 移除项 | 去向 | 原因 |
|--------|------|------|
| `provider`（所有字段） | `user_config.json` | Provider 按用户独立配置 |
| `knowledge`（所有字段） | 直接抛弃 | 不再保留全局知识库检索参数 |
| `skills`（白名单） | 直接抛弃 | 不再做全局级别 Skill 限制 |
| `expand`（白名单） | 直接抛弃 | 不再做全局级别拓展限制 |
| `perception`（白名单） | 直接抛弃 | 不再做全局级别感知限制 |
| `agent_models` | 直接抛弃 | 子智能体模型统一继承主模型 |
| `web`（host/port/log_level） | `.env` 环境变量 | `WEB_HOST` / `WEB_PORT` / `WEB_LOG_LEVEL` 等 |
| `prompt.include_*` 四个开关 | 直接抛弃 | 不再通过全局配置控制人格/手册/记忆注入开关 |
| `prompt.char_limits.knowledge_index` | 直接抛弃 | 知识库索引不再设字符上限 |
| `memory.injection_enabled` | 直接抛弃 | 记忆注入策略由 `injection_mode` 控制 |
| `memory.existing_candidates_for_extraction` | 直接抛弃 | 不再限制提取时的候选对比数 |
| `memory.tiers.permanent` | 直接抛弃 | 永久记忆不在此配置中声明，后台机制不变 |
| `task_plan.auto_accept` | 直接抛弃 | 任务计划默认需用户手动批准 |
| `cron.auto_start` | 直接抛弃 | 调度器默认随智能体启动 |
| `runtime_host.shutdown_timeout` | 直接抛弃 | 不再配置关闭等待超时 |
| `message.dedupe_max_entries` | 直接抛弃 | 上下文管理已有去重机制，冗余 |
| `message.bindings` | `config/message_config.json` | 账号绑定独立配置 |
| `message.transports` | `config/message_config.json` | 传输层配置独立管理 |
| `agents.n8_task_plan_max_steps` | 直接抛弃 | 与 `task_plan.max_steps` 冗余，统一由后者控制 |
