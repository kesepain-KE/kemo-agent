# 子代理配置规范

kemo-agent 子代理的注册、配置与触发规则完整说明。

更新时间：2026-07-19

---

## 目录结构

每个子代理位于 `agents/<name>/`，包含以下文件：

```
agents/<name>/
├── agent.json          # 注册定义（名称、版本、描述、触发文件）
├── agent-config.json   # 运行时配置（调用权限、工具、知识库、上下文）
├── trigger.md          # 触发规则与操作手册
├── AGENT.md            # 子代理自我运行手册（LLM 的 system prompt）
└── executor.py         # 入口函数
```

---

## agent.json — 注册定义

子代理的对外接口定义，只含 4 个字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | ✅ | 子代理唯一标识，通常与文件夹名相同 |
| `version` | string | ✅ | 语义化版本号，如 `1.0.0`、`2.0.0` |
| `description` | string | ✅ | 简短职责描述，一行中文 |
| `trigger` | string | ✅ | 指向同目录下的触发规则文件，如 `trigger.md` |

示例：

```json
{
  "name": "context_manage",
  "version": "1.0.0",
  "description": "按完整对话轮整理上下文并生成结构化历史摘要。",
  "trigger": "trigger.md"
}
```

## agent-config.json — 运行时配置

子代理的运行边界和资源权限，含 6 个字段：

### internal_mode

| 类型 | 默认 | 说明 |
|------|------|------|
| boolean | — | `true` 表示内部运行机制，不可被外界（用户/外部 API）直接调用 |

所有框架内置子代理均设为 `true`。用户自建的全局子代理如果不需要对外暴露，也应设为 `true`。

### allowed_callers

| 类型 | 默认 | 说明 |
|------|------|------|
| string[] | `[]` | 绑定调用模块白名单。`internal_mode: true` 时空数组表示允许任何模块调用 |

当前调用方类型：

| 值 | 说明 |
|---|---|
| `"engine"` | 对话引擎 `run/engine.py`，负责上下文压缩 |
| `"scheduler"` | 后台调度器，负责记忆巡检和自改进 |
| `"main_agent"` | 主智能体 AgentRunner，负责任务计划和定时任务 |

### tools

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `plugins.allow` | string[] | `[]` | 允许使用的 `plugins/` 下插件白名单，空数组禁止使用任何插件 |
| `shared_skills.allow` | string[] | `[]` | 允许使用的 `shared_skills/` 下共享技能白名单 |
| `max_iterations` | integer | `20` | 子代理被调用后最多执行多少轮工具调用。超过此值强制返回结果并标注原因 |

工具调用的超时时间继承 `config/global_config.json` 的 `tools.timeout`（当前为 **240 秒**）。

### global_knowledge / shared_knowledge

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `global_knowledge` | boolean | `false` | 是否允许查看 `global_knowledge/` 目录。允许时默认只注入索引文件内容 |
| `shared_knowledge` | boolean | `false` | 是否允许查看 `shared_knowledge/` 目录。允许时默认只注入索引文件内容 |

### inherit_main_history

| 类型 | 默认 | 说明 |
|------|------|------|
| boolean | `false` | 是否继承当前前端会话 `users/<name>/history/temp/` 的全部上下文 |

`true` 时子代理可以看到当前对话的完整历史；`false` 时只能看到调用方显式传入的数据。内部引擎代理（如 context_manage）和后台调度代理（如 self_improve）通常设为 `false`，主智能体调用的代理（如 task_plan、time_plan）通常设为 `true`。

## trigger.md — 触发规则与操作手册

每个子代理的触发规则文件，包含两个区域：

### 注册信息

注入到主智能体 system prompt 中的摘要。应包含：

- 名称
- 触发条件（什么时候该调用这个子代理）
- 职责（一句话）
- 模型（cheap / default / reasoning）
- 可用工具列表

### 操作信息

主智能体需要自行读取的详细操作手册。应包含：

- 调用方式（哪个模块调用、函数签名）
- 输入参数说明
- 输出格式说明
- 注意事项和边界条件

## 全局超时与生命周期

子代理自身没有运行时长硬限制，但受以下全局配置约束：

| 配置项 | 位置 | 值 | 说明 |
|------|------|------|------|
| 工具超时 | `config/global_config.json` → `tools.timeout` | 240 秒 | 每次工具调用的最长等待 |
| 默认超时 | `config/global_config.json` → `agent_runtime.default_timeout` | 600 秒 | 子代理总运行时间超过此后，主智能体可能查看状态并试图停止 |

## 当前内置子代理一览

| 子代理 | 调用方 | 工具 | 知识库 | 继承历史 | 触发条件 |
|--------|--------|------|--------|----------|----------|
| `context_manage` | engine | 无 | 无 | false | 对话轮次 ≥ max_rounds 或手动 /compress |
| `memory_temporary_important` | scheduler | 无 | 无 | false | 调度器定时唤起 |
| `self_improve` | scheduler | 无 | 无 | false | 调度器定时唤起 |
| `task_plan` | main_agent | knowledge_search | global+shared | true | 用户请求需多步骤分解 |
| `time_plan` | main_agent | get_current_time | 无 | true | 用户请求涉及定时任务 |
