# 拓展 2.0 组件面板模板状态

> 最后核对：2026-09-25。组件面板已经进入正式模板和创建链路，本文件只保留维护提醒。

## 当前状态

- `module/` 已包含 `panel.json`、`panel.values.json`、`status.json` 和 `README.md`。
- `expand_creater action=create` 会在临时目录内连同根合同文件一起复制组件目录，校验通过后再原子发布。
- 默认 `start_expand.py` 已实现面板声明的 `refresh`；默认 `data_update.py` 会写 Prompt 摘要和脱敏面板状态。
- Web 拓展页按请求读取组件声明，无需重启；已经打开的页面需要重新进入 Tab 或刷新。

## 维护要求

1. 不要把 `panel.json` 写进 `expand.json`；拓展清单仍拒绝未知字段。
2. 面板配置和值文件不会自动进入 Prompt；只有 `input_data.md` 属于数据注入出口。
3. 新增默认 action 时，必须同时在 `start_expand.py` 提供真实实现，不能留下可见但不可用的按钮。
4. 修改模板时同步更新创建器文件清单、组件解析测试、模板验收器和 `module/README.md`。
5. `data_update.py` 的 checkpoint/健康状态合同仍受 `tests/persistence/test_template_checkpoint_time.py` 保护。
