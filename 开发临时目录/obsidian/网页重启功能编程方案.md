# kemo-agent 网页重启功能 —— 编程方案

## 问题

当前智能体没有从网页端重启自身的能力。需要实现：用户在网页点击"重启"按钮 → 智能体使用当前端口重新启动。

## 方案

利用浏览器地址栏的 `window.location.port` 作为当前端口，前端将端口发给后端 API，后端调用 `restart.py --port=<port>` 重启。`restart.py` 用 `os._exit(0)` 硬退出释放端口，同时已启动一个独立的新进程在 2 秒后接管同一端口。

```
浏览器                                    后端                            restart.py
  │                                        │                                 │
  │  POST /api/system/restart              │                                 │
  │  {"port": 1360}                        │                                 │
  │ ──────────────────────────────────────→│                                 │
  │                                        │  subprocess.Popen([             │
  │                                        │    python, restart.py,          │
  │                                        │    --port=1360                  │
  │                                        │  ])                             │
  │                                        │ ──────────────────────────────→│
  │  {"ok": true}                          │                                 │
  │ ←──────────────────────────────────────│                                 │
  │                                        │                   起新进程、杀旧进程
  │                                        │                         os._exit(0)
  │  3秒后自动刷新 → new localhost:1360    │
```

## 详细规划

### 步骤 1：修改 `start_web.py`

**文件**：`E:\code\kemo-agent\start_web.py`

**操作**：删除刚加入的端口文件持久化逻辑。找到端口选定后的这段代码并删除：

```python
    # 持久化端口，供 restart.py 读取
    _port_file = root / "tmp" / ".web_port"
    _port_file.parent.mkdir(parents=True, exist_ok=True)
    _port_file.write_text(str(chosen_port))
```

这个删除后，`chosen_port` 之后紧接的就是 `# 5.启动RuntimeHost（除非--no-host）`。

### 步骤 2：重写 `restart.py`

**文件**：`E:\code\kemo-agent\restart.py`

**操作**：全量替换为以下内容：

```python
"""Restart kemo-agent with a specific web port.

Launches a new start_web.py instance in a detached process, then hard-exits
the current process. The caller must provide the target port.

Usage:
    python restart.py --port=1360
"""

from __future__ import annotations

import argparse
import os
import subprocess
import sys
import time
from pathlib import Path

ROOT = Path(__file__).resolve().parent


def main() -> None:
    parser = argparse.ArgumentParser(description="Restart kemo-agent")
    parser.add_argument("--port", type=int, required=True, help="Web port to restart on")
    args = parser.parse_args()

    port = args.port
    python = sys.executable
    start_script = str(ROOT / "start_web.py")

    print(f"[restart] 目标端口: {port}")
    print(f"[restart] 启动新进程: {python} {start_script} --port={port}")

    if sys.platform == "win32":
        restart_cmd = (
            f"Start-Sleep -Seconds 2; "
            f"& '{python}' '{start_script}' --port={port}"
        )
        subprocess.Popen(
            ["powershell", "-NoProfile", "-Command", restart_cmd],
            creationflags=subprocess.CREATE_NEW_PROCESS_GROUP | 0x00000008,
            cwd=str(ROOT),
        )
    else:
        restart_cmd = f"sleep 2 && exec '{python}' '{start_script}' --port={port}"
        subprocess.Popen(
            ["sh", "-c", restart_cmd],
            start_new_session=True,
            cwd=str(ROOT),
        )

    time.sleep(0.5)
    print("[restart] 正在退出当前进程...")
    os._exit(0)


if __name__ == "__main__":
    main()
```

### 步骤 3：添加后端 API 端点

**文件**：`E:\code\kemo-agent\web\app.py`

**操作**：在 `create_app` 函数内部、其他 `@app` 路由附近，新增以下路由。建议放在 `health` 路由之后。

```python
    # ── 新增 Pydantic 模型（放在文件顶部其他 Body 类旁边）──
    class RestartBody(BaseModel):
        port: int = Field(ge=1, le=65535)

    # ── 新增路由（放在 health 路由附近）──
    @app.post("/api/system/restart")
    async def restart_system(body: RestartBody) -> dict[str, Any]:
        import subprocess as _sp
        import sys as _sys
        restart_script = str(base / "restart.py")
        _sp.Popen(
            [_sys.executable, restart_script, f"--port={body.port}"],
            cwd=str(base),
        )
        return {"ok": True, "port": body.port}
```

**说明**：
- `RestartBody` 模型放在文件顶部其他 Body 类旁边（约第 50 行附近）
- 路由放在 `/api/health` 之后（约第 210 行附近）
- `base` 变量已经在 `create_app` 函数开头定义好了（第 123 行）
- 因为 `restart.py` 内部会 `os._exit(0)` 杀死整个进程（包括 Web 后端），所以这个端点本质上不需要返回有意义的结果——它只是触发重启。`return {"ok": True}` 会尽可能在退出前返回给前端，但不保证（进程可能在返回途中被杀）。

### 步骤 4：前端添加重启按钮

**目录**：`E:\code\kemo-agent\web\frontend\src/`

**操作**：在设置页面或其他合适位置添加一个"重启服务"按钮。按钮点击时：

1. 获取当前端口：`window.location.port || "80"`（按字符串保留，没有端口时传 `"80"`）
2. 调用 `POST /api/system/restart`，body 为 `{"port": <端口号>}`
3. 显示"正在重启…"提示
4. 等待 3 秒后 `window.location.reload()`

伪代码（具体技术栈请按前端项目现有代码风格调整）：

```tsx
// 在设置页或顶部栏添加
const handleRestart = async () => {
  const port = parseInt(window.location.port || "80", 10);
  try {
    await fetch("/api/system/restart", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify({ port }),
    });
  } catch {
    // 后端可能已经挂了，忽略 fetch 错误
  }
  // 等新进程启动后刷新
  setTimeout(() => {
    window.location.reload();
  }, 3000);
};

// 按钮
<button onClick={handleRestart}>重启服务</button>
```

**按钮放置建议**：设置页（SettingsPage）底部、"关于"区域，或顶部导航栏的用户菜单中。

---

## 应达到的效果

1. **端口不变**：重启前后的网页访问地址保持同一个端口，用户无需手动改 URL
2. **一键触发**：点击"重启服务"按钮 → 等待几秒 → 页面自动刷新 → 回到登录页（如已开启认证）
3. **无文件依赖**：端口信息直接由浏览器 URL 提供，不依赖 `tmp/` 文件留存
4. **跨平台**：`restart.py` 兼容 Windows（PowerShell + DETACHED_PROCESS）和 Linux/Mac（sh + start_new_session）
5. **命令行也兼容**：`python restart.py --port=1360` 仍然可以脱离 Web 单独使用
