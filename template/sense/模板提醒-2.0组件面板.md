# 感知 2.0 组件面板模板状态

> 最后核对：2026-09-25。组件面板已经进入正式模板和创建链路，本文件只保留维护提醒。

## 当前状态

- `module/` 已包含 `panel.json`、`panel.values.json`、`status.json` 和 `README.md`。
- `sense_creater action=create` 会在临时目录内连同根合同文件一起复制组件目录，校验通过后再原子发布。
- 默认 `data_update.py` 会读取用户配置、刷新 `sense.md`，并原子写入脱敏 `module/status.json`。
- Web 感知详情区按请求读取组件声明，无需重启；已经打开的页面需要重新选择模块或刷新。

## 维护要求

1. 不要把 `panel.json` 写进 `sense.json`；感知清单仍严格保持五字段。
2. 面板配置和值文件不会自动进入 Prompt；只有 `sense.md` 属于数据注入出口。
3. 感知 action 只允许框架内置零参数 `refresh`，不得在模板中声明模块私有遥控命令。
4. 修改模板时同步更新创建器文件清单、组件解析测试、模板验收器和 `module/README.md`。
5. `data_update.py` 的 checkpoint/健康状态合同仍受 `tests/persistence/test_template_checkpoint_time.py` 保护。
