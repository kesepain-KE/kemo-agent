# 拓展模块模板说明

将 `my_expand/` 目录复制到 `global_expand/<name>/`、`shared_expand/<name>/` 或 `users/<name>/expand/<name>/` 后，按以下规则修改。

## expand.json — 模块元信息

| 字段 | 说明 | 必须修改 |
|------|------|----------|
| `name` | 模块唯一标识，如 `system_volume`。决定目录名 | ✅ |
| `explain` | 模块功能描述，注入系统提示词 | ✅ |
| `open_input` | 是否启用数据注入（`input_data.md` → 系统提示词） | 按需 |
| `input_data` | 数据注入文件名，通常不改 | 不改 |
| `start_update` | 数据采集脚本，指向 `data_update.py` | 不改 |
| `open_control` | 是否启用操控能力（`start_expand.py`） | 按需 |
| `start_expand` | 操控入口脚本，指向 `start_expand.py` | 不改 |
| `start_control` | 操控说明文档，指向 `expand_control.md` | 不改 |

## data_update.py — 数据采集

核心逻辑在 `collect()` 函数中实现，返回 `dict`。`main()` 会自动将结果格式化为 Markdown 写入 `input_data.md` 并更新 `_last_run.json`。

## start_expand.py — 操控入口

核心逻辑在各 `xxx_action()` 函数中实现。`COMMANDS` 字典注册所有可用命令，`execute()` 是统一调度入口。主智能体通过 shell 调用：
```
python start_expand.py <command> [json_params]
```

## expand_control.md — 操控说明

注入系统提示词，告诉智能体有什么操控能力。分为"注入层"（当前数据状态）和"操作层"（可用工具函数签名）。

## input_data.md

由 `data_update.py` 自动覆盖写入，不需要手动修改。
